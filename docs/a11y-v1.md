## 3. 修复明细（优先改 `components/ui/`，一处生效全局）

### 3.1 语义与标签

- **侧栏会话行嵌套交互**（`nested-interactive` 174 节点，全部页面）：`SessionList` 原本是 `div role="button"`，内部又放了「会话操作」按钮。改为「行容器 + 打开会话的真实 `<button data-session-open>` + 并列的图标按钮」，方向键逐行导航仍聚焦打开按钮；行高、选中态、hover 与 ⋯ 菜单位置不变。
- **模型选择器可访问名与可见文字不一致**（`label-content-name-mismatch` 70 节点）：`MenuSelect` / `ModelMenu` 的 `aria-label` 改为「字段名：当前值」（如「选择模型：Mock 2 高」），既保留字段语义，也让可见文字出现在名称里。
- **无标签 textarea**（`label` critical 2 节点）：设置 → 提示词的编辑框补 `aria-label`。
- **地标与文档结构**：App 内容列改为 `<main>`，桌面/移动侧栏外层改为 `<aside aria-label="侧栏">`，侧栏拖拽分隔条随之进入地标；设置导航 `<nav aria-label="设置页签">`；组件画廊内的 `<header>` 改为普通容器，消除重复 banner。
- **允许缩放**：`index.html` 移除 `maximum-scale=1.0`（`meta-viewport` 56 节点）。

### 3.2 对比度（以 `docs/design.md` 的 token 为准，仅调不达标处）

- 新增 `--t-accent-text`：浅色 `#A34E2F`、深色 `#E6957A`。橙色文字（待审批时间、可编辑徽标、反馈/计划标记）在侧栏、卡片、浅色底上均 ≥4.5:1。
- 新增 `--t-accent-strong` / `--t-accent-strong-hover`：浅色 `#A34E2F → #8F4227`，深色 `#B45536 → #C6613F`。仅用于「发送」等橙底白字按钮与数量徽标，白字对比度 ≥4.7:1；品牌橙 `--t-accent` 仍保留给 logo、焦点装饰。
- 深色 `--t-muted` / `--t-text-tertiary`：`#A3A3A3 → #B8B8B8`。修复选中行（`--t-bg-active #474747`）与 hover 层上 12–13px 次要文字仅 4.14:1 的问题，改后 ≥4.68:1。浅色 token 不变。

### 3.3 焦点环（关键）

`outline-none` 会把 Tailwind 的 `--tw-outline-style` 置为 `none`，导致层内的 `focus-visible:outline-2` 只设置宽度、样式仍为 `none`——**修复前多数按钮/输入框的焦点环实际不可见**。修复方式：在 `index.css` 所有 `@layer` 之外增加统一规则：

```css
:where(a, button, input, select, textarea, summary, [tabindex]):focus-visible {
  outline: 2px solid var(--t-accent-strong);
  outline-offset: 2px;
}
```

未分层规则优先于 `utilities`，保证焦点环真正绘制；diff 行与会话行向内收 `-2px`，避免被滚动容器裁切。Tab 顺序、深色/浅色下均已逐项截图确认。

### 3.4 弹层、菜单与焦点归还

- **Popover 关闭后焦点掉到 body**：Anchor 是包裹 `div`，Radix 默认把焦点还给不可聚焦的 div。`Popover` 增加 `onCloseAutoFocus`，关闭时聚焦 Anchor 内第一个可聚焦控件（文件夹选择、委派策略等触发器）。
- **菜单键盘导航失效**：React 19 + Radix Portal 下，菜单收到箭头键却不移动焦点、Enter 不选择。`ui/Menu` 增加 `handleMenuKeys` 兜底：↑↓/Home/End 移动、Enter/Space 激活、子菜单 Enter 打开；焦点延后一帧落位，避让 Radix RovingFocus 的回拉。`MenuList` 原有键盘实现不变。
- **Modal 焦点陷阱**：打开瞬间焦点在面板本身时，Shift+Tab 会逃到背景（实测落到改动审阅的「更多提交操作」）。补上「焦点不在可 Tab 列表内 → Shift+Tab 去最后一项 / Tab 去第一项」。
- **Tooltip 作为无障碍描述**：`Tip` / `Tooltip` 生成隐藏文案节点，并把 `aria-describedby` 挂到宿主（或内部第一个可聚焦控件）；悬停与键盘聚焦都能被读屏读出，卸载时清理。

### 3.5 键盘操作流

- **Shift+Tab 被输入框劫持**：Composer 原本用 Shift+Tab 循环权限模式，导致反向 Tab 永远离不开输入框。权限模式切换改为 **Alt+Shift+Tab**，Shift+Tab 恢复浏览器默认焦点后退；tooltip 文案同步。
- **审批快捷键 1/2/3 在发送后不可用**：发送后焦点回到输入框，审批卡的全局 1/2/3 监听会忽略输入框。新审批出现且输入框为空时，120ms 后把焦点交给「允许」按钮（正在输入排队消息时不抢焦点）；键盘用户可直接按 1/2/3。
- **改动审阅无法键盘评论**：diff 行原本只有 pointer 事件。现在每行可聚焦（`role="group"` + `aria-label`「新/旧文件第 N 行：…」），Enter/Space 选中并自动聚焦行内评论框，Enter 提交、Esc 取消。
- **读屏实时播报**：`ChatView` 增加 `role="status" aria-live="polite"` 区域，新审批出现时播报「新的审批请求：…，共 N 项待处理」，流式回复结束播报「回复已完成」。
- **减少动效**：沿用全局 `prefers-reduced-motion: reduce`（动画与过渡压到 0.01ms，退出位移动画改为淡入）；新增元素未引入额外位移动画。

## 4. 纯键盘走查记录（`e2e/keyboard-walk.mjs`）

流程：Ctrl+N 新建会话 → Shift+Tab 到文件夹 → Enter 打开目录弹层（焦点进入搜索框）→ 输入路径 Enter → Tab 到模型 → Enter 打开菜单、Esc 验证归还焦点 → 重新打开选 Mock 2 → 打开思考强度子菜单选「高」→ Tab 到发送 → Enter → 依次按 1 / 2 / 3 处理 Bash / Write / Edit 三次审批 → Shift+Tab 到「改动审阅」Enter → Tab 到 diff 行 Enter → 输入评论 Enter → Tab 到侧栏「设置」Enter → 焦点进入弹层、Shift+Tab 不逃逸 → 切「通用」→ 选「恢复为暂停」→ Esc 关闭，焦点回到「设置」并带可见外环。

全部断言通过。每次断言同时检查：

- `document.activeElement !== body`；
- `:focus-visible === true` 且 `outline-style` 非 `none`、宽度 2px；
- 弹层打开后焦点进入弹层；
- Esc 关闭后焦点回到触发按钮；
- Modal 内 Tab / Shift+Tab 循环不逃逸。

## 6. 遗留与建议

- 组件画廊中「禁用」控件按设计保持 40% 不透明，axe 对禁用控件不计对比度；恢复启用后仍应保持 token 对比度。
- 深色 `--t-muted` 提到 `#B8B8B8` 后，与 `--t-text-secondary #D2D2D2` 的层次差略缩小；视觉走查未见「灰蒙蒙」回退，如后续觉得层次不足，可只在不与 `--t-bg-active` 叠加的文字上使用 `--t-text-tertiary`。
- Radix Portal 的键盘处理是当前依赖版本的兼容兜底；升级 `@radix-ui/react-menu` 后应重跑 `scripts/a11y-scan.mjs` 与 `e2e/keyboard-walk.mjs`，确认兜底不重复移动焦点。
- 移动端触控目标 44px、手机抽屉焦点管理沿用既有实现；本轮 axe 在 1440×900 桌面视口验证，手机视口由 regression 的触控用例覆盖。
