# 账号制工作区：多机代测步骤（给产品所有者）

> 全程在公司内网 / VPN，**不要做端口映射或公网暴露**。测试机可以是 Windows / Linux / macOS，Node ≥ 22；每台机器的 Tandem 版本一致。真实 Key 不必配置，登录与机器列表不依赖模型。

## 1. 准备三台机器

假设：

- **A**：账号中心（你也日常用的一台）
- **B**、**C**：另外两台
- A 的内网地址：`http://192.168.1.10:8270`（以 `ipconfig` / `ip addr` 为准）

每台机器启动 Host 时监听局域网（仅在公司网段）：

```bash
tandem-host --host 0.0.0.0
# 桌面端：默认 8270；手机/浏览器打开 http://<该机IP>:8270/?token=<主token>
```

确认 B、C 能打开 `http://A的IP:8270`（能看到 Tandem 登录页）。Windows 防火墙只放行公司网段。

## 2. 在 A 创建工作区

1. A 上打开「设置 → 成员与分享 → 工作区」。
2. 在「在这台主机创建工作区」填：工作区名称、所有者用户名（3–32 位）、密码（≥ 8 位）→ **创建工作区并登录**。
3. 页面显示「账号中心」与 A 的主机；点 **生成加入码**（24 小时、一次性）。
4. 复制加入码与 A 的地址。

## 3. B、C 加入

在 B（再重复到 C）：

1. 「设置 → 成员与分享 → 工作区」→「加入已有工作区」。
2. 填 A 的地址（`http://192.168.1.10:8270`）+ 加入码 → 加入。
3. 加入成功后用 A 上创建的所有者账号登录一次；应看到 A/B/C 三台机器。
4. 回到 A 的工作区页点「刷新令牌」或重新打开设置：主机列表应有 3 台。
   - 看不到 B/C：确认 B/C 加入时填的是 A 的**局域网 IP**（不能填 127.0.0.1），且 A 能访问 B/C 的 IP。
   - 加入码只能用一次；失败就重新生成。

## 4. 建同事账号

在 A 的工作区页 →「新建账号」：

1. **协作者**：用户名 `chen`、密码、角色「协作者」、范围「指定机器」→ 勾选 **B**。可选「指定项目」并填 `B 的主机 id | /home/chen/project`（主机 id 在主机列表地址旁；需绝对路径）。
2. **观察者**：用户名 `guan`、密码、角色「观察者」、范围「全部机器」。

在**全新客户端**（另一台电脑浏览器隐私窗口 / 手机清空 App 数据）打开任意一台的 Tandem 地址：

1. 侧栏底部「登录工作区」→ 账号中心地址填 A 的地址 → 分别用 chen / guan 登录。
2. **chen**：主机切换器只出现 B；会话列表只显示授权项目下的会话；发消息正常。
3. **guan**：能看到 A/B/C；打开会话只能看，输入框不可用；直接调发送接口应 403（可选）。
4. 回到所有者：三台机器都在，切换后能各自新建会话。

## 5. 刷新、吊销与中心离线

- **换设备**：清空 localStorage 后重新登录，机器列表应自动出现（不抄 token）。
- **吊销**：A 的工作区页对 chen 点垃圾桶 → 确认。chen 的客户端下一次请求应 401，已开的 WS 被断开；在 B、C 上都应失效（中心会推送签名快照，离线 Host 10 秒内轮询到）。
- **中心短暂下线**：把 A 的 Host 停 2 分钟，已登录的 guan/chen 在**访问令牌有效期内**（默认 30 分钟）仍可继续使用 B/C；刷新令牌、登录新设备会失败。恢复 A 后点「刷新令牌」应成功。
- **单机模式**：不做工作区的机器继续保持「添加主机：地址 + token」；工作区登录与手工主机可以并存。

## 6. 收尾与安全

- 测试完在 A 工作区页吊销测试账号；B/C 若不再使用，在各自工作区页「本机退出工作区」。
- 加入码、账号密码、token 不要发到公网群聊或截图；`~/.tandem/accounts.json` 按敏感配置对待（600 权限，含中心私钥）。
- 中心被攻破 = 工作区全部 Host 可被接管：账号中心只放在你信任的机器上，默认只监听回环或防火墙白名单；怀疑泄露时在所有 Host「退出工作区」，重建工作区。
- 需要回传的信息：每步的截图、哪台机器/哪个角色、浏览器控制台报错、A 的 Host 日志（`~/.tandem` 同目录或桌面端日志）。
