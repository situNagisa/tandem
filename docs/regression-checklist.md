# 回归清单（2026-11-07）

来源：`docs/qa-v6.md`、`docs/bugs-v6.md`、`docs/review-v4.md`、`docs/review-v5.md`、
`docs/review-v7a.md`、`docs/review-v7b.md`、`docs/review-v7c.md` 中标记「已修」的 P0/P1 条目。
每条由 `e2e/regression.mjs` 起临时 Host（`TANDEM_HOME=/tmp/tandem-reg-<随机>`、随机端口）复现，
桌面视口 2552×1274、手机视口 390×844。`npm run regression`，或 `node scripts/check.mjs` 第 5 步。

## 轮次条 / 长会话

1. **长会话打开停在顶部而不是最新消息**
   - 现象：40 条以上消息的会话首次打开停在顶部，距底部一百多像素。
   - 复现：打开 40 轮会话 → 等待加载完成 → 检查 `.chat-scroll` 是否贴底、最后一条用户消息是否在视口内。
   - 用例：`长会话打开贴在最新消息`。
2. **轮次条点击刻度跳到相邻/更远轮次（75→76、76→55、80→38）**
   - 现象：点击第 N 轮刻度，落点不是第 N 轮；松手后窗口重排又二次跳转。
   - 复现：悬停轮次条等大纲展开 → 点击第 30 轮行 → 断言 `aria-valuenow=30`、第 30 轮消息在视口顶部、计数胶囊为「第 30 / 40 轮」。
   - 用例：`轮次条点击第 30 轮精准定位（不跳到相邻轮）`。

## 设置窗口 / 弹窗

3. **设置窗口切换页签时高度与位置跳动**
   - 现象：438 → 600 → 718px 来回跳，弹窗上下移动。
   - 复现：打开设置，依次切账号/Host/权限/MCP/用量/同步/外观/记忆，记录弹窗 bbox 必须恒为 1320×920（2552×1274）。
   - 用例：`设置窗口固定尺寸，切换页签不跳动`。
4. **弹窗焦点不进入、Tab 逃逸、关闭后焦点丢失**
   - 现象：打开设置焦点仍在背景；Tab 能跑到侧栏；关闭后焦点掉到 body。
   - 复现：打开设置 → 连续 25 次 Tab 均须留在 dialog 内 → Esc 关闭后焦点回到「设置」按钮。
   - 用例：`设置弹窗焦点陷阱与关闭后焦点还原`。
5. **手机设置导航占 445px、首屏看不到内容**
   - 现象：16 个页签两列，语音/分享页内容从 y≈500 开始。
   - 复现：390×844 打开设置 → 导航必须 3 列、高 ≤360px、页签触控 ≥44px、弹窗全屏且无横向溢出。
   - 用例：`手机设置全屏、三列导航且无横向溢出`。
6. **手机嵌套弹窗按 Esc 一次关两层**
   - 现象：MCP 删除确认叠在设置上时，Esc 连设置一起关掉。
   - 复现：手机设置 → MCP → 删除服务器 → Esc，确认框消失而设置仍在。
   - 用例：`手机嵌套弹窗按 Esc 只关闭最上层`。

## 新会话 / 输入框

7. **新会话默认工作目录为空，发送只提示「先选择一个工作目录」**
   - 现象：Host 的 homeDir 晚到，cwd 一直为空，发送像没反应。
   - 复现：打开新会话 → 等 Host 信息到达 → 目录胶囊 title 必须是绝对路径 → 发送后新建会话 `cwd` 非空。
   - 用例：`新会话默认带上工作目录且双击发送只创建一次`。
8. **连续快速点发送创建两个会话**
   - 现象：第二次点击在 React 重渲染前仍能进入 submit。
   - 复现：同一个事件循环内触发两次发送点击 → `POST /api/sessions` 只能有 1 次。
   - 用例：同上。
9. **已在首页再点侧栏「新会话」没有任何变化**
   - 现象：页面、Host/目录、草稿都不重置。
   - 复现：会话页输入草稿 → 点「新会话」→ 再输入草稿 → 再点「新会话」→ 输入框应为空且获得焦点。
   - 用例：`侧栏「新会话」清空草稿并聚焦输入框`。
10. **粘贴一次图片生成多个附件**
    - 现象：剪贴板同一张图同时出现在 `items` 与 `files`，被重复添加。
    - 复现：向输入框派发包含两个同字节 File 的 paste 事件 → 只能出现 1 个「移除图片」。
    - 用例：`粘贴一次同一张图片只生成一个附件`。

## 环境条 / 顶栏

11. **手机环境条右侧被裁切、触控 24px**
    - 现象：390px 下 `scrollWidth 403/408 > clientWidth 358`，Worktree 超出屏幕。
    - 复现：390×844 打开仓库会话 → 环境条 `scrollWidth ≤ clientWidth`、每个触发项右缘 ≤390、高度 ≥44px、容器透明。
    - 用例：`手机环境条不越界、容器透明、触控 44px`。
12. **环境条容器透明（设计取向）**
    - 现象：环境条应坐在对话背景上，只在悬停/展开时给底色。
    - 复现：桌面会话页检查环境条容器背景为 transparent，触发器文字 ≥13px 且不越界。
    - 用例：`环境条容器透明、触发器可见且不越界`。
13. **环境条文件夹弹层被裁切**
    - 现象：输入框上方弹层向下弹被裁或越出视口。
    - 复现：点文件夹胶囊 → 弹层 `data-side=top`、完整位于视口内、目录列表可用。
    - 用例：`环境条文件夹弹层向上弹出且完整可见`。
14. **Windows 桌面顶栏 48px 与 36px 系统按钮错位**
    - 现象：win32 注入后顶栏仍 48px，右侧 140px 留白与按钮垂直错位。
    - 复现：注入 `window.tandemDesktop={isDesktop:true,platform:'win32'}` → 顶栏高 36px、右 padding 140px、按钮不越界/不溢出。
    - 用例：`Windows 桌面顶栏 36px 且按钮不溢出`。
15. **断线后 2.5s 内仍显示在线**
    - 现象：`setOffline` 后侧栏与顶栏不变，发送进入僵尸连接。
    - 复现：打开会话 → `context.setOffline(true)` → 6s 内出现「重新连接中…」。
    - 用例：`断网后立即显示重新连接条`。

## 模型菜单 / 会话列表

16. **非当前模型看起来像禁用；分组层级过弱**
    - 现象：可选模型全 `text-muted`，分组只缩进 6px。
    - 复现：打开模型菜单 → 条目可读、无 disabled；账号子菜单列出全部分组。
    - 用例：`模型菜单级联（账号 → 分组 → 模型）可用且不越界`。
17. **模型菜单贴近一屏、底部账号需要滚动且无提示**
    - 现象：三账号 + 分组时菜单接近一屏。
    - 复现：菜单 bbox 在视口内；子菜单同样不越界。
    - 用例：同上。
18. **侧栏会话 ⋯ 菜单 / tooltip 被侧栏裁切**
    - 现象：菜单和完整标题 tooltip 被侧栏 overflow 裁掉。
    - 复现：悬停会话行 → 打开「会话操作」菜单 → 悬停会话标题 → 菜单与 `#tandem-tooltip` 都必须整体位于视口内。
    - 用例：`侧栏会话 ⋯ 菜单与 tooltip 不被裁切`。

## 消息 / 回退 / 文件链接

19. **Windows 盘符路径（`/D:/...`）不被识别为文件链接**
    - 现象：`D:\repo\a.ts`、`/D:/repo/a.ts`、`file:///D:/...` 打开无效或路径错误。
    - 复现：消息里含 `[D 盘文件](/D:/repo/demo.ts:2)` 与行内 `` `D:\repo\demo.ts` `` → 点击后预览标题含 `D:/repo/demo.ts`，内容为盘符文件。
    - 用例：`Windows 盘符路径文件链接可打开预览`。
20. **回退对话框不展示被回退的用户消息**
    - 现象：破坏性操作缺少最关键的上下文。
    - 复现：用户消息「回退到此处」→ 对话框必须引用「第 2 轮：检查文件」并完整位于视口内。
    - 用例：`回退对话框引用目标消息并显示删除范围`。
21. **触屏消息操作是游离的「…」且无文字**
    - 现象：`hover:none` 下每条消息一个孤立图标。
    - 复现：390×844 会话页 → 桌面操作条不显示；只剩一个「消息操作」按钮且高 ≥44px。
    - 用例：`手机消息操作只剩一个更多操作按钮且触控 44px`。

## 改动审阅

22. **未跟踪目录被折叠成一条，无法单独查看/丢弃**
    - 现象：git 把 `dir/` 作为一条未跟踪记录，文件列表只显示目录。
    - 复现：仓库含 `untracked-dir/one.ts` 与 `untracked-dir/nested/two.ts` → 改动审阅列出两个文件，选中后显示未跟踪文件 diff。
    - 用例：`改动审阅把未跟踪目录展开为文件`。
23. **行内评论发送后对应行没有任何标记**
    - 现象：评论只在 diff 底部列表出现，长 diff 中与代码失去锚定。
    - 复现：选中增行 → 浮窗输入 → Enter → 该行出现评论标记与 `data-commented`，底部显示「1 条评论」。
    - 用例：`改动审阅行内评论浮窗与行标记`。
24. **「提交」实际 `git add -A` 但界面未说明范围**
    - 现象：未跟踪临时文件被一并提交，且没有二次确认。
    - 复现：改动审阅 → 按钮文案「提交 N 个文件」→ 输入信息点击 → 弹出「提交全部改动」并提示含未跟踪文件。
    - 用例：`改动审阅提交范围带文件数与二次确认`。

## 账号 / 同步 / 配对 / MCP

25. **自定义 OpenAI 兼容账号被误标为 DeepSeek**
    - 现象：`presetForProfile` 回落到同 kind 的第一个预设。
    - 复现：编辑 baseUrl 不在预设列表的账号 → 显示「自定义接口」，不得出现 DeepSeek。
    - 用例：`自定义兼容账号显示「自定义接口」而不是 DeepSeek`。
26. **同步与备份：空口令仍可点击导出**
    - 现象：点击后才报错。
    - 复现：设置 → 同步与备份 → 口令为空时「导出并下载」必须 disabled。
    - 用例：`同步与备份：空口令时导出按钮禁用`。
27. **替换导入立即清空现有账号与 Host，没有二次确认**
    - 现象：选「替换」后点导入即生效；「替换」无危险色。
    - 复现：选择配置文件和口令 → 选「替换」→ 点「导入配置」→ 必须弹出确认，说明将清空的账号/Host 数量；取消不产生副作用。
    - 用例：`同步与备份：替换导入需二次确认并标注危险`。
28. **Host 只监听回环时仍展示扫不通的二维码**
    - 现象：手机上二维码地址指向手机自己，提示却写「扫码即可连接」。
    - 复现：Host 监听 127.0.0.1 → 设置 → Host 管理 → 连接手机 → 显示「手机暂时连不上这台 Host」，不出现二维码。
    - 用例：`只监听回环时「连接手机」不展示二维码`。
29. **MCP 垃圾桶单击立即删除配置**
    - 现象：误触即丢失 `mcp.json` 条目。
    - 复现：设置 → MCP → 删除服务器 → 出现「移除 MCP 服务器」确认；取消后文件仍保留。
    - 用例：`移除 MCP 服务器需要二次确认`。
30. **worktree 会话顶栏/侧栏按隔离目录 basename（cache）归组**
    - 现象：顶栏显示「cache」，侧栏与主仓库分开。
    - 复现：打开 worktree 会话 → 侧栏必须按原仓库名归组，不出现独立的 `cache` 分组。
    - 用例：`worktree 会话按原仓库归组而不是目录名 cache`。

## 记忆 / 提示词 / 字号 / 用量 / 续跑

31. **记忆编辑器第一行暴露 `<!-- tandem-memory {...} -->`**
    - 现象：用户可能误删内部元数据。
    - 复现：设置 → 记忆 → 编辑全局记忆 → 文本域不含 `tandem-memory`，但保留正文条目。
    - 用例：`记忆编辑器不暴露内部元数据行`。
32. **记忆/提示词/Skills 页出现 9.5/10.5px 文字**
    - 现象：低于设计硬规则（仅 kbd 与极小徽标允许 11px）。
    - 复现：逐页遍历可见文本节点，最小字号 ≥11px。
    - 用例：`设置页字号不低于 11px（记忆/提示词/Skills）`。
33. **手机提示词点列表项看不到编辑区**
    - 现象：编辑框在 y≈1406（视口 844），点击后像没反应。
    - 复现：390×844 → 设置 → 提示词 → 点第一个条目 → 编辑区顶部进入视口（y<720）。
    - 用例：`手机提示词点选后编辑区滚入视口`。
34. **用量图在手机上缩成约 5px 文字且无法查看每日金额**
    - 现象：固定 640×168 viewBox 被整体缩放，柱状图只能 hover。
    - 复现：390×844 → 设置 → 用量 → 图表宽度 ≥300px；点按柱子出现当日日期与金额 tooltip。
    - 用例：`手机用量柱状图可点按查看每日花费`。
35. **断点续跑胶囊完全不显示**
    - 现象：`summaryOf` 漏掉 `retryInfo`，顶栏条件永不成立。
    - 复现：会话 JSON 含 `retryInfo` → 桌面顶栏出现「网络中断，N 秒后重试 · 立即重试 · 停止」。
    - 用例：`断点续跑胶囊显示倒计时与操作`。
36. **手机断点续跑胶囊与标题/轮次/PR 按钮重叠**
    - 现象：胶囊整行宽内联渲染，文字互相压住。
    - 复现：390×844 打开 retry 会话 → 胶囊在顶栏下方独立一行、宽度 390、顶栏内不出现「网络中断」。
    - 用例：`手机重试胶囊独立一行且不压顶栏`。
