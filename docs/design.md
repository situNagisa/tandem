# Tandem 设计规范 v2（参考 Claude 桌面 app / claude.ai/code）

> 更新：2026-11-09。

气质：温暖、安静、克制。大量留白，暖色中性灰，唯一强调色为 Claude 橙；靠细边框、层次背景和微动效体现精致，不靠重阴影和饱和色。

## 色板 v3（2026-11-06 依据用户提供的 Claude Code Desktop 深色截图取色重定）
原则：**几乎无彩色**。层次只靠中性灰的明度差（深色约 4 级：#191919 / #1F1F1F / #2A2A2A / #303030 / 选中 #404040）。
强调色橙只用于：品牌 logo、发送按钮、焦点环、待审批提示。**不再使用绿色/红色表达状态**：
- 在线/空闲/成功 → 不显示或中性灰点；运行中 → 中性色转圈/呼吸点（--text-secondary）；待审批 → 橙点。
- 错误 → 文字用 --danger（低饱和砖红，仅文字，不做色块背景）；离线 → --text-tertiary 灰点。
- diff 增删：深色用极低不透明度底色（+ rgba(255,255,255,.06) 与左侧 2px 竖条 + "+/−" 符号区分；增行竖条 #8A9A7B 灰绿、删行 #A87363 灰砖，饱和度 <25%），文字保持主文字色。不出现鲜绿鲜红。
- "危险操作"按钮：中性按钮 + hover 时文字转 --danger，不要红框红底。

## 侧栏信息层级（参考 Claude Code Desktop 截图）
- 顶部：主操作列表式（图标+文字，无边框）："新会话"、"搜索"——**全应用只此一个新会话入口**（另保留 Ctrl/Cmd+N 快捷键）。
- 分组标题：12px --text-tertiary，可折叠的小三角；组标题右侧 hover 出现 "+"（在该项目下新建会话）。
- 层级用缩进与字号/字重区分，不用框和底色：Host（仅在 ≥2 个 Host 时显示为一级分组，13px 中字重+服务器图标）→ 项目（13px 常规+文件夹图标，--text-secondary）→ 会话（13.5px，--text-secondary，选中 --text + --bg-active 圆角 8）。

## 字号与对比度（2026-11-07 全局提亮，替换旧值）

### 无障碍补充（2026-11-07）

- 橙色文字单独用 `--t-accent-text`：浅色 `#A34E2F`、深色 `#E6957A`；橙底白字按钮/徽标用 `--t-accent-strong`（浅 `#A34E2F` / 深 `#B45536`，hover 各深/浅一档）。品牌橙 `--t-accent` 仍只用于 logo、焦点装饰与非文字色块。
- 深色 `--t-muted` / `--t-text-tertiary` 提到 `#B8B8B8`：保证在选中行 `#474747` 与 hover 层上仍 ≥4.5:1；浅色不变。
- 键盘焦点环统一为 `2px solid var(--t-focus-ring)`（中性灰）、offset 2（diff 行与会话行向内收 -2px）。**只跟键盘导航走**：鼠标点开弹层后自动聚焦的输入框不画焦点环（文本输入框在鼠标聚焦后也会命中 `:focus-visible`，所以由 `lib/focusRing.ts` 记录输入方式，CSS 只在 `html[data-input-modality="keyboard"]` 时画环）。焦点环不再使用强调橙，属 R04 收敛；键盘 Tab 时仍然显示且对比度达标。旧实现里 `outline-none` 会把 `--tw-outline-style` 置为 none，导致 `focus-visible:outline-2` 只剩宽度、没有样式；统一规则必须放在所有 `@layer` 之外。
- 权限模式切换快捷键改为 **Alt+Shift+Tab**，Shift+Tab 不再被输入框劫持；审批出现时若输入框为空，焦点自动交给「允许」，1/2/3 可直接使用。

### 字号下限（硬规则）
- 正文、消息、列表、按钮、菜单项、输入框：**≥ 13px**；紧凑行行高 1.4–1.5。
- 次要说明、时间、标签、设置帮助：**≥ 12px**。
- 仅 kbd 键帽与极小徽标允许 **11px**；禁止 9/10px 文本。
- 28px 高控件可用 13px 字，保持高度不变；菜单单行选项 26–32px 高，字 13px。
- 侧栏会话标题 14.5–15px（14 已偏小），项目名 13.5px，时间 12px；右侧栏卡片标题 12px / 值 13px；环境条 13px；工具行 13px；Composer 底栏 13px；设置页正文 13.5px（输入/值 13px）。
- 次要文字不用 300 细体：标题 500–600，按钮 500，正文 400。

- 圆角：小控件 6，按钮/菜单项 8，卡片/Popover 12，输入框卡片 18–20，发送按钮圆形。

## 按钮与控件

全应用共用 `src/components/ui/Button.tsx`（Button / IconButton）与 `Controls.tsx`（Input / Select / SegmentedControl / Switch），不再手写高度、圆角与 hover。

**尺寸档**（高度 / 圆角 / 图标 / 水平内边距）：

| 档位 | 高度 | 圆角 | 图标 | 用途 |
|---|---|---|---|---|
| sm | 28 | 6 | 14 | 密集工具栏、菜单、图标按钮 |
| md（默认） | 32 | 8 | 16 | 常规按钮、对话框次要操作 |
| lg | 36 | 10 | 16 | 对话框主操作、空态主按钮 |

- 文字统一 13px / 500；不随档位改字号，图标按档位 14 / 16。
- 变体：
  - `primary`：**白底黑字**（深色 #EFEFEF 底 / #191919 字；浅色 #1A1A1A 底 / #FFFFFF 字），对齐 Claude Code Desktop 的主按钮，用于允许、确认、保存等主操作。2026-11-06 用户要求：审批卡等按钮用白色，不用橙色。
  - `accent`：橙色底，仅输入框发送按钮与品牌位置。
  - `secondary`：`--bg-subtle` 底 + 1px hairline 边框，默认变体。
  - `ghost`：无底无框，hover `--bg-hover`。
  - `danger-ghost`：中性按钮，hover 仅文字转 `--danger`，不做红底红框。
  - `icon`：正方形，同尺寸档（IconButton）。
- 焦点：`focus-visible` 2px 橙色外环、offset 2；不与 hover 混用。
- disabled：40% 不透明、`cursor: not-allowed`、不响应 hover。
- 按下：`scale(.98)`，80ms；不影响布局。
- 图标按钮必须有 `aria-label`；需要说明时用统一 Tooltip（悬停/聚焦出现，文案 ≤220px），不再各写 `title`。发送按钮保留圆形，字号与图标仍按 md 档。
- 输入框 / 下拉 / 分段控件高度与按钮档对齐（28 / 32 / 36），分段控件容器用 `--bg-subtle`、选中用 `--bg-active`；开关 36×20，选中态也用中性灰，不用橙色。
- 移动端 <768px 的触控目标仍保持 ≥44px：可在外层容器放宽，不改变桌面档位。
- 橙色的边界不变：只用于品牌、发送、焦点、待审批；选中态一律中性（`--border-strong` + `--bg-subtle`/`--bg-active` + 勾选标记），不用橙边框、橙 ring、橙点。

## 动效
- 时长：微交互 120ms，Popover/菜单 160ms，抽屉/对话框 220ms。
- 缓动：`--ease-out: cubic-bezier(.16,1,.3,1)`；退出用 `cubic-bezier(.4,0,1,1)` 且更快（100ms）。
- Popover/菜单：opacity 0→1 + scale .97→1，transform-origin 指向触发点。
- 消息进入：opacity + translateY(4px→0)，仅新消息。工具展开：高度过渡（grid-rows 0fr→1fr）。
- `prefers-reduced-motion: reduce` 时关闭位移动画。
- **轮次条（第 3 轮反馈）**：静止是一列极简刻度（当前轮最长 + 轮号，两侧按距离衰减），靠近 70ms 后**同一批元素以弹簧"长"成**半透明轮次大纲面板（280px，浮在内容上、不占布局、不压滚动条）：每行 = 轮号 + 用户消息首行 + 行尾刻度；悬停高亮条与当前轮指示条各自弹簧跟随；**按下拖动 = 对话区实时预览，松手确定**，面板上下边缘停留 = 加速滚动，滚轮逐轮、Alt+↑/↓、聚焦后 ↑↓/PgUp/PgDn/Home/End。只写 transform/opacity，DOM 池 25 个元素按轮号循环复用（150 轮与 1500 轮同价），按消息 id 定位、每帧取实时落点，不依赖估算行高；reduced-motion 下直接切换。手机端无此条：顶栏"第 N/M 轮"胶囊打开底部抽屉大纲（定高行虚拟化）。

## 布局
- 侧栏默认 272px，可拖拽 220–400，记住宽度；Ctrl/Cmd+B 收起。
- 对话内容列最大宽 760px 居中；输入框同宽，贴底，底部留 16–20px。
- 顶栏 48px，无边框背景与对话区一致，滚动后出现 hairline 下边框。
- 移动端 <768px：侧栏为左滑抽屉（遮罩 + 跟手），输入框贴底含安全区，触控目标 ≥44px。

## 组件要点
- **侧栏**：顶部「新会话」按钮 + 搜索；会话按 Host → 项目（env.repoName 或 cwd basename）分组，组头小号次要色 + 分支名，可折叠；会话项单行标题 + 右侧相对时间，hover 显示 ⋯；状态：运行中 = 橙色呼吸点，待审批 = 实心橙点；置顶区在最上。底部：设置、主题。
- **用户消息**：右对齐，--bg-subtle 圆角 16 气泡，最大宽 85%。
- **Assistant**：无气泡纯排版。
- **工具行**：13px --text-tertiary，图标 14px + 动词 + 目标（"读取 src/a.ts"、"运行 npm test"、"编辑 src/b.ts +3 −1"），右侧 chevron；连续 ≥3 个工具折叠为"使用了 N 个工具"。运行中图标转圈；错误为 --danger。

## 2026-11-09 用户决定：工作站改为客户端-服务模式（替代"账号中心"）

## 2026-11-09 用户要求：进入先登录 / 一行命令添加主机 / 调试版演示主机

- **进入先登录**：打开 Tandem（桌面、网页、手机）先看到登录/注册页；未登录时任何路由（含深链）都只显示登录页，地址栏保留原路由，登录后跳回。登录后才看到主界面。
- **没有主机不能开会话**：账号下没有主机时主界面显示空状态「先添加一台主机」，新会话入口禁用并说明原因；添加后自动出现。登录 ≠ 添加主机，本机也要显式添加。
- **一行命令添加主机**：客户端给出按平台切换（Windows PowerShell / macOS / Linux）的一行命令，令牌一次性、15 分钟有效、单次使用；目标机执行后以当前账号身份**持久**连接（Linux systemd --user、macOS launchd、Windows 计划任务，断线重连），客户端实时显示「等待主机连接… → 已连接 <主机名>」。长期凭据只存主机本地（0600）。安装脚本与主机包由工作站自己提供，不接公网/第三方。
- **Windows 安装包**：用户实测 `tar.exe: Invalid empty pathname` 失败——安装包不再用 tar/夹具，只打运行所需文件，路径断言 ASCII；Windows 改 ZIP + `Expand-Archive`；失败必须打印可执行的手动安装步骤。
- **桌面「添加这台电脑」**：本机一键完成，不复制命令。
- **调试版**：登录页有「使用调试账号登录」；回环地址打开时桌面与网页都自动登录调试账号（`TANDEM_DEBUG_ACCOUNT=0` 关闭），账号自动带本机 + 一台「演示主机」（演示模型/会话/设备在演示主机下）；退出后记住不自动登录。发布版没有调试登录与演示主机。
