# 内网团队共享 v1（成员 / 邀请 / 审计）

> **只在可信内网使用。** Tandem Host 默认是「一台机器 + 一个所有者」的本地工具；本功能让同一内网的同事以受限身份连接这台 Host，全部逻辑与数据都在 Host 本地完成：没有公网服务、没有第三方账号体系、没有云端推送。v1 使用 HTTP 明文，仅适合公司内网 / VPN，**不要做端口映射或公网暴露**。

## 1. 角色与权限矩阵

| 能力 | 所有者（主 token） | 观察者 | 审批者 | 协作者 |
|---|---|---|---|---|
| 查看授权项目的会话列表 / 内容 / 文件 | ✓ | ✓ | ✓ | ✓ |
| 处理审批（允许 / 拒绝 / 总是允许） | ✓ | — | ✓ | ✓ |
| 转交审批给其他审批者 | ✓ | — | ✓ | ✓ |
| 发送消息 / 中断 / 重试 | ✓ | — | — | ✓ |
| 在授权项目新建会话 | ✓ | — | — | ✓ |
| 修改账号 / Key / 设置 / 权限规则 / Hooks / MCP | ✓ | — | — | — |
| 查看 Key（含掩码）与配置导出 | ✓ | — | — | — |
| 管理成员 / 邀请 / 审计 | ✓ | — | — | — |

- 会话可见范围按成员的 `projectDirs` 过滤：会话 `cwd` 或 worktree 所属仓库在授权目录内才可见；子代理会话同理。未授权会话在 REST 返回 404，列表里直接不出现。
- 文件浏览 / 读取 / `@` 补全同样限制在授权目录内；符号链接按真实路径校验。
- 成员读 `/api/profiles` 只拿到账号名、模型列表与分组，Key 掩码被清空；所有写接口与 Key 测试接口返回 403。
- 成员的角色 / 项目目录变更会立即断开其现有 WS 连接，客户端用同一 token 重连后按新权限执行；吊销后 token 立即失效。

## 2. 邀请与 token

1. 所有者在「设置 → 成员」选择角色与项目目录，生成邀请。
2. Host 生成 24 小时有效、**只能使用一次**的邀请码；链接形如 `http://<host>:<port>/#invite=<code>`，同时提供二维码。
3. 同事打开链接（或在自己的 Tandem「Host 管理」里粘贴链接），填写名字后客户端调用公开接口 `POST /api/team/invites/accept`。
4. Host 校验邀请码哈希与有效期，创建成员并返回 `tmm_…` 成员 token；**token 只在这一次响应里出现**。
5. Host 只保存 token 的 SHA-256（`~/.tandem/team.json`，600 权限、原子替换）；邀请码同样只存哈希。
6. 所有者可随时吊销成员：现有 WS 立即断开，之后的请求 401；删除邀请记录不会吊销已加入的成员。

注意：
- 邀请码就是一次性凭证，等同于「加入权限」。通过可信渠道发送，不要发到公网群聊或工单截图。
- 成员 token 存在客户端 localStorage；拿到 token 即拥有该成员的全部权限。丢失设备时请在 Host 端吊销。
- 主 token（所有者）仍是全权限，`config.json` 中的主 token 不要发给同事。

## 3. 服务端边界

- REST：`server.ts` 的全局 `onRequest` 先解析 token（主 token → 所有者；`tmm_…` → 成员），再执行 `team/access.ts` 的白名单守卫。成员默认拒绝，只有会话读取、文件读取（限授权目录）、账号只读、`/api/team/me`、`/api/team/approvers` 等少量接口放行。
- WS：连接建立时记录成员身份；`subscribe` 校验会话可见性，`send` / `interrupt` / `retry_now` 需要协作者，`permission` 需要审批权且必须能看到该会话。
- 审批事件：`permission_request` / `permission_resolved` / `permission_transferred` 只投递给所有者与有审批权的成员；转交后仅目标成员与所有者收到该审批。收件箱快照同样按角色与项目过滤。
- 在线状态：会话的 WS 订阅者列表（含所有者）以 `presence` 事件下发，界面只显示头像首字母与角色；离开会话或断线即消失。
- 审计：记录邀请创建/接受、成员修改/吊销、新建会话、发送消息、审批决定与转交；最近 200 条，存 `team.json`，仅所有者可读。v1 不记录消息正文与命令全文（只记工具名与决定）。

## 4. 威胁模型

| 场景 | 结果 / 缓解 |
|---|---|
| 同事只拿到观察者 token | 只能看授权项目内容；写操作 403，WS 发送被拒。 |
| 邀请链接泄露 | 24 小时内可被使用一次；所有者在成员页删除未使用邀请即可作废。 |
| 成员 token 泄露 | 拥有该成员权限；立即在成员页吊销，现有连接被断开，token 失效。 |
| 内网窃听 / 中间人 | v1 是 HTTP 明文，token 与内容可能被同网段攻击者截获。**只用可信内网 / VPN，机器防火墙限制来源。** 后续版本再考虑 TLS。 |
| 恶意协作者 | 可以在授权项目里发消息、让 agent 调用工具；工具仍需审批（或已有规则）。不能改权限规则、Key、Hooks、MCP、设置，不能把会话范围扩到未授权目录。授权项目内的文件（包括 `.env` 等秘密）对观察者及以上可见，授权前请确认目录内容。 |
| 观察者截屏 / 复制会话 | 只读权限本身允许查看内容，无法阻止人工外传；不要把秘密会话分享给不应看到的人。 |
| Host 被公网暴露 | 不在支持范围内。禁止端口映射、反向代理到公网、使用第三方隧道。 |

## 5. 运维建议

- Host 用 `--host 0.0.0.0` 监听局域网时，配合系统防火墙只允许公司网段访问端口；不确定时保持默认 `127.0.0.1`。
- 定期在「设置 → 成员」检查成员、在线状态与审计；离职/换机立即吊销。
- `~/.tandem/team.json` 含成员哈希与审计，按敏感配置对待；备份时不要上传到公共位置。
- 成员的项目目录必须是 Host 上真实存在的目录；新增项目时编辑成员即可，变更会强制其重连。

## 6. v1 已知限制

- 无 TLS / 无证书校验；无 SSO、无第三方账号。
- 权限粒度到「项目目录 + 角色」，没有单会话 ACL。
- 在线状态仅代表 WS 连接，不代表成员正在看屏幕。
- 审计不做导出、不落 IP、不记录审批内容全文。
- 成员客户端的设置页只保留 Host 管理 / 外观 / 通知；其他 Host 级设置页由服务端 403 兜底。
