# Tandem 内部体验评审 v4

评审对象：`packages/web` + `packages/server` · 视口 1440×900 / 390×844 · 浅色 / 深色
方法：真实 Host（3 账号含 2 分组、7 会话、真实 git 工作区改动、本地 OpenAI 兼容桩服务触发真实审批）+ Playwright 截图与交互；控制台除断网期间 WebSocket 连接失败外无 error。
基线：Claude Code Desktop / claude.ai；规范：`docs/design.md`。
本轮重点：改动审阅、检查点回退、权限规则与「添加为规则」、断线重连与 seq、复制/编辑/草稿/粘贴/历史、运行计时、通知、快捷键、账号分组、外部会话导入、同步备份。

## 结论

未发现阻断级 P0。共记录 26 条：P1 9 条、P2 17 条。本轮的明显问题集中在「会话打开不在底部」「用户消息操作在触屏上变成游离图标」「自定义兼容账号被误标为 DeepSeek」「危险操作缺少范围提示/二次确认」；均已在本轮修复。行内评论的锚点可见性、移动端文件行丢弃入口等问题保留为 P2。

## 已验证的交互

- 改动审阅：文件列表含 modified / added / untracked / deleted，行号与 +/- 统计正确；点击 diff 行出现行内输入，Enter 发送评论；丢弃 untracked 弹出含「直接删除文件」警告的确认框；提交后可继续审阅新改动。
- 审批：「添加为规则」预填 `Bash` + `npm test*` + 允许，写入 Host 规则后设置页可见；审批卡允许/拒绝/总是允许快捷键正常。
- 回退：用户消息悬停可进入对话框，识别 2 个快照文件；取消不产生副作用。
- 断线：杀掉 Host 后 2.5s 内出现「重新连接中… 立即重试」，重启 Host 后 5s 内自动恢复；seq 从快照续接，无重复消息。
- 草稿：切换会话后恢复；>2000 字粘贴折叠为「粘贴的文本 · 801 行 4.8k 字」并可移除；运行计时、待审批计时、模型菜单分组、账号编辑分组均正常。
- 浅/深色与 390px/1440px 无页面级横向溢出；移动端审阅面板全屏且底部提交区可达。
