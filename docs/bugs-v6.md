## 一、新会话页按钮“点了没反应”

| 位置 | 现象 | 根因 | 状态 |
| --- | --- | --- | --- |
| `components/NewSessionDialog.tsx` | 打开新会话页，工作目录胶囊显示“工作目录”，直接输入或点示例提示词后发送，只出现“先选择一个工作目录”，用户感觉按钮/发送没反应 | 初始化 cwd 的 effect 只在 `hostId` 变化时执行；Host 的 `homeDir` 通过 WS 稍后才到，effect 不会因 `info` 到达而重跑，`cwd` 一直为空。`submit()` 因此直接返回错误，示例提示词也只填字不发 | 已修复：cwd 依赖 `homeDir`，Host 变化时切到该 Host 最近目录/主目录，`info` 晚到也会补上；目录胶囊显示目录名（如 `nagisa`）而不是“工作目录”。`c4889e5` |
| 同上 | 连续快速点发送可能创建两个会话 | 第一次点击后 `sending` 要等 React 重渲染才生效，第二次点击在渲染前仍能进入 `submit` | 已修复：`sendingRef` 同步去重；双击发送实测只产生 1 个 `POST /api/sessions`。`3ef2484` |

验证（修复后）：

- 3 个示例提示词：点击后均填入输入框并聚焦（与 Claude 一致，不直接发送）。
- 会话欢迎页 4 张建议卡：均填入并聚焦。
- Host 胶囊 / 目录胶囊 / 模型菜单 / 权限菜单：均能打开，Esc、点外关闭；目录胶囊标题与内容正确。
- 最近目录、上一级、刷新、主目录、使用此目录：均响应；目录列表可滚动。
- worktree 开关：目录为 git 仓库时可切换并出现分支输入；非 git 目录显示“隔离分支（需 Git 仓库）”并禁用（保留原设计）。
- 发送：默认 cwd 下直接发送成功（实测 `POST /api/sessions` 的 `cwd` 为 Host 主目录）。
- 添加图片：会打开文件选择器（`filechooser` 事件触发，支持多选），非 bug。
- 注：`3c39da1` 已收敛重复入口，新会话页不再有独立的“账号/模型胶囊”，账号与模型统一由 Composer 内的模型菜单选择；该菜单已验证可用。

## 二、设置窗口尺寸跳动

| 位置 | 现象 | 根因 | 状态 |
| --- | --- | --- | --- |
| `components/settings/SettingsDialog.tsx` | 打开设置，在“账号与模型 / Host / 权限 / MCP / 用量 / 同步与备份 / 外观”之间切换时窗口高度在 438 → 600 → 718px 之间跳，位置上下移动，晃眼 | Modal 只设置了 `max-w-3xl`，内容区用 `min-h-[360px] max-h-[min(76dvh,640px)]` 随每个 Tab 内容自适应高度 | 已修复：桌面固定 `min(880px,92vw) × min(640px,86vh)`；左侧导航固定 176px；右侧内容区独立滚动；切换 Tab 只做 120ms 淡入（`motion-reduce` 下关闭），无尺寸动画；手机全屏（`max-sm:fixed inset-0`，顶部/底部安全区）。`6033646` `1418c7d` |

验证：

- 7 个 Tab 在 1440×900 下的弹窗实测均为 880×640，位置不变；内容超长时右侧滚动（用量 562、同步 714、外观 685），页面无横向溢出。
- 390×844 下弹窗为 390×844 全屏，导航两列，内容独立滚动，底部操作（权限保存、同步导出等）可达。
- 深色模式下尺寸与滚动一致。
- 各设置页无 sticky footer 依赖；子对话框（MCP 添加/移除、Host 移除、连接手机）在桌面和手机均完整显示，Esc 逐层关闭，嵌套弹窗不会一次关两层。
- 设置页切换 Tab 不再触发布局跳动；内容淡入 120ms。

## 三、其他修复

| 位置 | 现象 | 根因 | 状态 |

| `components/ui/Modal.tsx` | 打开设置后焦点还留在背景的“设置”按钮上；Tab 能跑到侧栏/输入框；关闭后焦点掉到 body 或随机元素；子弹窗关闭后也不会回到触发按钮 | Modal 未做焦点进入、焦点陷阱与恢复；嵌套弹窗按条件渲染，关闭时组件直接卸载，原来的恢复逻辑等不到 effect | 已修复：打开时记录触发元素并把焦点移入弹窗；Tab/Shift+Tab 在顶层弹窗内循环；关闭或卸载后焦点还原到触发元素（含嵌套弹窗）。实测 30 次 Tab 未逃逸，嵌套 MCP 弹窗关闭后回到“添加服务器”。`3ef2484` |

| `components/settings/SyncSection.tsx` | “导出并下载”在加密口令为空时仍可点击，只在点击后报错 | 按钮 `disabled` 只判断 `exporting` | 已修复：口令为空时禁用；输入口令后可导出，实测生成配置并出现成功 toast。`3ef2484` |
| `components/NewSessionDialog.tsx` | 连续点击发送产生重复请求 | 见上表 | 已修复。`3ef2484` |
