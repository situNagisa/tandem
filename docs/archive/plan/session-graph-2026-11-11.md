## 2. 显示与不显示

显示：
- 主线每个用户轮一个节点：标题 = 用户首行（单行省略）；固定轮带图钉；当前所在轮外圈 ring。
- 子代理分支：始终展开，一个子代理轮一行，标题 = 该轮首行；不再有单独的「子代理 · N 步」行，也不含步数。
- 分叉分支：一个节点，标题 = 分叉会话标题，行尾「分叉」小字。
- 线：主线、子代理分出/汇回、分叉各一条轨道线；子代理与分叉靠「是否汇回」区分。

不显示：
- 卡片/全高标题行的汇总（`8 轮 · 4 子代理 · 1 分叉`）。
- 轮次序号（`1`、`2`…）与 `第 N 步` 序号。
- token、成本、耗时等任何用量数字（行内与 tooltip 均不显示；用量仍只在右侧「用量与预算」卡片展示）。
- 「结果已返回」行、展开/收起按钮（`▸`）、子代理行前 `└`、`+N` 嵌套数量。

## 3. 布局

- **时间倒序**：最新的一轮在最上，越早越下（#06）。所有行号在布局末尾统一翻转，因此分支在视觉上从父节点向上延伸。主线仍固定第 0 列竖直，分支向右展开。
- **轨道式（B）**：正交圆角折线（圆角 6px）、统一 2px 线宽；行高 28px、列间距 12px；列复用（行区间不相交的分支共用一列，`assignColumns`），同轮并行/嵌套分支占相邻列；水平线只在转折点接触别的线。
- **汇回规则（#08）**：取消结果节点。子代理的最后一行直接由一条 `data-merge` 的汇回线接回父会话：
  - 父会话在父泳道上有下一轮时，汇回线的端点落在那一轮的节点上；
  - 是父会话最后一轮时，端点落在父泳道下一行（主线轨道向前延伸一格覆盖该端点，不留空行提示）。
  - 嵌套子代理同理，汇回父子代理泳道上的下一轮节点或紧随其后的轨道行。
- **节点与线端点**：分枝线从父节点圆心出发，到子泳道最后一个自有节点圆心；汇回线从该节点圆心出发，端点落在父泳道节点圆心或父轨道行（x 为父泳道中心、y 为行中心）。
- **泳道列分配**：颜色按泳道号循环（`--graph-lane-1..7`），列按复用后的位置；主线恒 `--graph-lane-0`。节点与文字起点由列数决定，文字不再被泳道挤到 ~100px（B 的收益）。
- 空会话保留一行空态。

## 4. 交互

- **点主线轮节点**：对话区定位该轮（含懒加载），行为同 `focusMessage`。
- **在子代理只读视图里点主线轮节点（#03）**：先退出子代理视图（`closeAgentSession`），再按 `focusMessage` 定位该轮；不会出现「点了没反应」。
- **点子代理轮节点**：打开该子代理只读会话（面包屑可返回）；不再有展开按钮。
- **点分叉节点**：打开分叉会话。
- **悬停线（#10）**：任一轨道线都有 ≥12px 透明命中描边（`pointer-events: stroke`）。悬停时该会话的整条轨道（分出 + 汇回）保持全亮，其余线降到 22% 不透明度；标准 Tooltip（`data-tip`）显示归属会话名：主线=当前会话标题，子代理线=该子代理标题，分叉线=分叉会话标题。线的命中区不覆盖节点文字/圆点：节点行只在文字区域接管指针。
- **键盘**：节点按视觉顺序（上→下）排列，↑/↓ 移动选中并滚动到视口，Enter 打开；`role="tree"`、`aria-selected` 保留。

## 5. 卡片与全高展开

- 右栏卡片：标题行仍由 Card 组件提供（`会话图` + 右上角「全高显示会话图」图标）；**不另起汇总/展开按钮行**，卡片内容直接是会话图。高度 = 3–12 行（84–336px），超出在卡片内滚动。
- 全高展开（`data-graph-full`）：顶部只有「← 返回 · 会话图」，不显示汇总；图占满剩余高度，内部滚动。
- 只读视图（外部会话、子代理内嵌）共用同一渲染组件，不提供展开与跳转提示。

## 6. 覆盖滚动条（#07，共享层）

- 覆盖式滚动条仍只有一个实例、不占布局、不改外观（6px 圆角）。
- 纵向轨道向右让位：若滚动容器自身没有内边距，向上最多找 4 层祖先，取**最外层**满足「右内边距 ≥12px 且与本容器右缘距离 ≤48px」的 gutter；否则退回自身右缘 3px。这样镶嵌在卡片/面板里的滚动容器（会话图）的滚动条落在卡片外的面板留白里，不压住卡片头部的折叠/拖动/展开控件。横向轨道同理（向下找 gutter）。
- 该规则作用于所有滚动区域（设置、右栏、弹层），不是会话图特例。

## 7. 被替代的旧决定

以下旧行为由本包原话取代，现行文档与检查不再按旧行为断言：

1. 卡片标题行显示「N 轮 · N 子代理 · N 分叉」，全高页头重复一次 → 只保留 Card 标题与「会话图」标签（#01）。
2. 子代理默认收起为「子代理 · 名称 · N 步」节点，`▸` 展开、`└` 标记展开后的轮 → 始终展开、无按钮（#02/#04）。
3. 子代理泳道末端有「结果已返回」节点，汇回线从该结果行出发 → 无结果行，从最后一行直接汇回父会话（#08）。
4. 主线节点标题前显示轮号 → 去掉（#05）。
5. 行内与 tooltip 显示 token/成本/耗时 → 全部不显示 token（#09）；tooltip 只保留会话名。
6. 「自上而下与对话顺序一致」（最早在上）→ 时间倒序，最新在上（#06）。
7. 子代理分支在展开后仍只显示 ▸/收起语义 → 删除展开状态与 `expanded` 布局参数。
8. 子代理视图里点主线节点仅调用 `focusMessage`（主会话未挂载，无反应）→ 先退出子代理视图再定位（#03）。
9. 覆盖滚动条「贴在滚动容器自身右缘」→ 嵌套容器时贴最近（最外层）带内边距祖先的 gutter（#07）。

保留了旧决定：8px 同形圆节点、泳道色变量与配色、子代理 `data-merge`、分叉不合并 +「分叉」、3–12 行高度、列复用、当前轮 ring、图钉、分叉/子代理点击打开会话、键盘浏览、跳转互斥。

## 8. 验证

- 单测（`layout.test.ts`）：倒序行号、主线只有一条、子代理始终展开、无结果节点、汇回端点落在父轮节点或父轨道、嵌套列复用不交叉、320 轮 < 20ms、卡片高度 3–12 行。
- 回归（`e2e/regression.mjs`「会话图」）：无汇总行、无序号、无 token、无「结果已返回」、无展开按钮；节点顺序最新在上；悬停线高亮 + tooltip 为会话名；子代理视图点主线节点回主会话并高亮该轮；覆盖滚动条不遮挡卡片头部控件（`elementFromPoint`）；分叉点击与全高展开仍可用。
- 决定检查（`decisions-check.mjs`）：`graph-no-meta`（无汇总/序号/token/结果行/展开按钮）、`graph-reversed`、`graph-edge-hover`、`graph-main-click-from-subagent`。
