# 账号制 v1：工作区 / 账号中心 / 按账号授权

> 目标：一个人管 5 台机器只登录一次；同事加入一次，按账号授权到「哪些机器 / 哪些项目 / 什么角色」；离职吊销一次全部失效。
> 约束：**不接任何公网或第三方账号服务**。账号中心完全自托管在用户自己的 Host 上，只在可信内网 / VPN 使用；不想用账号的单机用户保持现在的「地址 + token」方式不变。

## 1. 场景

1. 一个人 5 台机器（家里/公司/笔记本/远端 Linux）：任意客户端登录一次，侧栏自动出现全部机器，直连 / SSH 隧道 / 中继哪种能通就用哪种。
2. 同事加入：所有者发一次邀请（账号 + 角色 + 范围），对方登录一次就拥有被授权的机器与项目；不需要在每台机器上重复邀请。
3. 换新电脑：登录后机器列表自动出现，不手工抄地址与 token。
4. 离职：账号中心吊销账号 → 各 Host 立即失效（REST 401、WS 断开、刷新令牌作废）。
5. 单机用户：不创建工作区，继续用现有主 token / 成员 token。

## 2. 核心概念

- **工作区（Workspace）**：一组互相信任的 Host，有唯一 `workspaceId` 与显示名。
- **账号中心（Account Center）**：工作区里兼任身份服务的一台 Host（用户选择）。保存账号、角色、授权、吊销列表；签发令牌；提供登录 / 刷新 / 工作区快照接口。v1 只支持一个中心；备用中心列入以后（需数据同步与选主，v1 不做）。
- **加入码**：中心生成的一次性码（24h、只存 SHA-256）。另一台 Host 在「工作区」页填「中心地址 + 加入码」加入；中心记录该 Host（id/名称/可达地址），加入方保存中心公钥。之后它信任中心签发的令牌，**本地验签，不逐次回源**。
- **令牌**：Ed25519 签名的紧凑令牌（`acw_` + base64url(header.payload.sig)）。
  - 访问令牌默认 30 分钟，含账号 id、名称、角色、范围、工作区 id、签发/过期时间与 `jti`。
  - 刷新令牌默认 7 天，只在账号中心有效；刷新时轮换，旧刷新令牌立即作废。
  - 各 Host 用中心公钥本地验签 + 校验过期 + 校验吊销列表；**中心短暂下线时，已签发的访问令牌在有效期内仍可用**（刷新要等中心恢复）。
  - 令牌不是 cookie 会话：客户端按 Host 存到 localStorage（与现有 token 同一位置），请求头仍是 `Authorization: Bearer`。
- **吊销**：中心维护 `revoked[accountId] = 时间`，生成**中心签名的吊销快照**；加入时登记了地址的 Host 会被中心主动推送（签名校验），同时各 Host 每 10 秒拉取一次快照兜底。吊销账号 = 该账号所有未过期令牌立即失效。
- **审计**：中心记录账号创建/修改/吊销、登录成功/失败、加入码创建/使用、Host 加入/移除；各 Host 记录账号发起的会话/审批/设备操作（带账号 id）。

## 3. 账号

- 用户名 + 密码：`scrypt`（N=16384, r=8, p=1，随机 16B salt，Node 内置实现，无第三方依赖），只存哈希。
- 可选 TOTP 二次验证（RFC 6238，30s 步长，±1 窗口；中心生成 secret，客户端扫码/手输）。
- 可选「只用设备密钥登录」：客户端生成 Ed25519 密钥对，登录时提交公钥（首次信任）或对中心一次性挑战签名；适用于无密码的桌面/手机。
- 账号状态：`active | disabled`；吊销 = 写入吊销快照，账号保留可复查。
- 首次初始化中心时创建「所有者」账号（用户名 + 密码），此后只有所有者 / 管理员能建号。

## 4. 权限模型

角色 × 范围，`scope` 三选一：`all`（工作区全部 Host）/ `hosts`（指定 Host 列表）/ `projects`（按 Host 指定项目目录）。

| 能力 | 所有者 | 管理员 | 协作者 | 审批者 | 观察者 |
|---|---|---|---|---|---|
| 管理工作区（加入码、Host、账号、授权、吊销） | ✓ | — | — | — | — |
| 范围内 Host：设置 / 账号 Key / 成员 / 插件与 Hooks | ✓ | ✓ | — | — | — |
| 范围内 Host：会话读写、发消息、中断、新建会话、审批 | ✓ | ✓ | ✓ | 只审批 | — |
| 范围内 Host：只读会话 / 文件 / 设备列表 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 设备操作 / 串口写入（受现有审批与锁） | ✓ | ✓ | ✓ | — | — |
| 网关调用（按账号额度） | ✓ | ✓ | ✓ | ✓ | ✓ |

- 「管理员」是范围内 Host 的本机管理员（可改该 Host 设置/Key），但**不能**管理账号中心、不能改工作区授权。
- 项目范围落到 Host 上的绝对路径（与现有成员 `projectDirs` 同一套可见性/文件边界实现）；服务端按账号 id + Host 计算有效角色，范围外一律 404/403，不暴露存在性。
- **设备**：账号令牌可直接调用 `/api/devices*`，角色门槛与上表一致；跨 Host 设备挂载 v1 仍用设备级令牌（`dvt_`），但「能否挂载/操作」由账号角色决定。以后改为账号中心签发短期设备凭据。
- **网关**：v1 继续用 `tgw_` 网关令牌（OpenAI/Anthropic 兼容入口不变）；中心在账号页为账号签发/绑定网关令牌，吊销账号时一并禁用。网关用量按账号统计。以后把网关令牌收敛为账号令牌的派生凭据。
- 现有 **成员（`tmm_`）**：完全保留、优先级不变；账号令牌是新增凭据类型。迁移路径：在账号中心按现有成员建账号（同角色、同项目目录）→ 通知成员改用账号登录 → 各 Host 上吊销/删除旧成员 token。迁移前后可并存，不强制一次性切换。
- 现有 **设备令牌（`dvt_`）**、**网关令牌（`tgw_`）**：继续有效；账号中心可登记其归属账号，吊销账号时联动禁用（v1 由中心在推送中附带 `revokedGatewayTokens`，Host 本地屏蔽；未登记的令牌不受影响）。

## 5. 客户端

- **登录页**：填「账号中心地址 + 用户名 + 密码（或设备密钥）」。成功后返回访问/刷新令牌、账号信息、可访问 Host 列表（id/名称/可达地址/连接方式/本地角色与项目）。
- 登录后自动把 Host 写进现有主机列表（同一套存储与连接逻辑），并选中第一台；之后每台 Host 的请求都用同一份访问令牌，过期前自动向中心刷新，中心不可达时提示「令牌过期后需重新连接中心」。
- **连接方式**：v1 登录后自动添加 Host 上报的**直连地址**（优先与账号中心同主机的地址）；已经用 SSH 隧道或中继添加过的主机保持原样，不会被登录覆盖。SSH / 中继地址的自动发现列入以后（见 §7），v1 仍用现有「设置 → 主机」添加。
- **账号菜单**（侧栏底部，设置旁）：显示账号名 / 角色；菜单含「工作区管理」「退出登录」「切换账号」。未登录时不显示。
- **工作区管理页**（设置 → 成员与分享 → 工作区）：
  - 所有者：创建工作区、生成加入码、Host 列表（名称/地址/在线/移除）、账号列表（新建/改角色与范围/禁用/吊销）、审计。
  - 加入方 Host 的管理员：填中心地址 + 加入码加入、查看本机所属工作区与中心状态、退出工作区（本地不再信任中心令牌）。
- **单机模式**：不登录也能用；「添加主机」填地址 + token 的老流程原样保留；有工作区登录时两类 Host 可并存。

## 6. 安全

- 只在可信内网 / VPN 使用；v1 明文 HTTP（与团队功能一致），**禁止端口映射、公网反向代理、第三方隧道**。TLS / mTLS 列入以后。
- 令牌有效期：访问 30 分钟、刷新 7 天（默认值，写在 `accounts.json` 可调）；刷新令牌一次性轮换；登出即作废当前刷新令牌。
- 吊销：中心签名快照 + 主动推送 + 10s 轮询；Host 收到快照后立即拒绝该账号的 REST 请求，并对该账号的 WS 连接执行断开。加入码 24h、一次有效，中心可随时作废未使用的码。
- 审计：账号维度（谁、在哪台 Host、做了什么）；登录失败按用户名 + 来源 Host 记录（不记密码/令牌），连续失败仅记日志，v1 不做全局锁定（避免内网误锁）。
- **中心被攻破的影响**：攻击者可签发任意账号令牌与吊销快照 → 等价于工作区全部 Host 被接管。缓解：中心只跑在所有者信任的机器、默认只听回环或内网防火墙白名单、`accounts.json` 600 权限、定期备份；各 Host 可随时「退出工作区」立即停止信任（本地删除中心公钥），中心私钥泄露时在所有 Host 退出工作区并重建。加入方 Host 不能反向签发令牌（只持公钥）。
- **加入方 Host 被攻破**：只能伪造自己的 Host 上报与审计，不能伪造其他 Host 的令牌（中心私钥不在它手里）；中心可将其移出工作区。
- 重放 / 盗用：访问令牌短命 + 刷新轮换；快照带版本号（只接受不低于本地版本的新快照，防止重放旧快照复活已吊销账号）与中心签名；快照接口另需加入方 Host 的共享口令，同网段普通客户端不能枚举全部机器。内网窃听者可在有效期内冒用访问令牌（明文 HTTP 的已知边界），因此不把工作区跨到不可信网络。

## 7. v1 范围与以后

**v1 做**：工作区创建 / 加入码加入（Host 间交换公钥）/ 本地验签；账号（密码 + 可选 TOTP + 设备密钥预留）；角色 × 范围；登录页 + 自动机器列表 + 账号菜单 + 工作区管理页；访问/刷新令牌与轮换；吊销快照推送 + 轮询；设备/网关接入现有权限门槛；单机模式与现有 token 完全兼容；回归与代测文档。

**v1 不做**：备用账号中心与多中心同步；LDAP / OIDC / SSO；账号分组嵌套与自定义角色；单会话 ACL；跨工作区联邦；账号级流量配额（沿用网关限额）；设备短期凭据（仍用 `dvt_`）；SSH / 中继地址自动发现；多所有者（v1 只有一个所有者，不可吊销最后一个所有者）；TLS / mTLS；推送通知。

**以后**：备用中心（只读副本 + 手动提升）；中心数据加密备份；账号令牌派生设备/网关凭据；TLS 与请求签名；登录失败锁定与告警；WebAuthn；按账号的审计导出。
