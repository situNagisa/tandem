## P1

1. **记忆编辑框暴露内部元数据行**（`MemoryEditorDialog.tsx`）
   编辑区第一行是 `<!-- tandem-memory {"project":...} -->`；预览区已隐藏，编辑区却显示。用户可能误删/误改，且「已修改」状态会被内部字段干扰。应读出时剥掉元数据、保存时由 Host 重新补写。
2. **手机环境条被裁切且触控不达标**（`EnvBar.tsx`）
   390px 下环境条 `scrollWidth 403 > clientWidth 358`，Worktree 控件右缘到 419px，超出屏幕；只能靠无提示的横向滑动才能碰到。触发按钮高 24px，低于移动端 ≥44px 的规则。
3. **手机「设置-提示词」点击列表项看不到编辑区**（`PromptsSection.tsx`）
   列表在上、编辑区在下；点击「身份说明」后页面滚动位置不变，编辑框在 1406px（视口高 844），用户会以为没反应。应在小屏选中后把编辑区滚入视口。
4. **字号低于设计硬规则**（提示词 / 记忆 / 子代理 / Skills / 系统提示行）
   - 禁止的 9.5px：提示词列表「已改/项目」徽标。
   - 10.5px：提示词分类标题、可编辑/只读/已修改/未保存徽标、变量名、字数统计；子代理「继承主会话模型」等徽标；记忆「全局」徽标；系统提示分段来源徽标与 token 数。
   - 11.5px：提示词说明与告警、子代理页脚注、Skills 路径与分组计数、派单按钮内文字/页脚说明。
   - 记忆编辑框正文 12.5px（输入内容应 13px）。
   规则：正文/列表/输入 ≥13，次要 ≥12，仅 kbd 与极小徽标可 11，禁止 9/10。
