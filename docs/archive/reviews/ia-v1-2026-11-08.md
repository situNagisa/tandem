| 类型 | 问题 | 影响 |

## 3. 收敛方案

### 3.1 设置：7 组 19 页

分组顺序按使用频率；每组内页面按使用频率排序。低频专家页收进默认折叠的「高级」。

| 分组 | 页面（按频率） | 说明 |
|---|---|---|
| 基础 | 通用、主机 | 首次使用与连接 |
| 模型与账号 | 账号与模型、自动路由、用量与预算 | 合并「用量」+「预算」 |
| 权限与安全 | 权限、Secrets | 审批、沙箱、网络白名单、项目密钥 |
| Agent 与自动化 | Agent 能力（子代理 / Skills / 提示词）、定时任务、记忆 | 合并三个 agent 配置页 |
| 团队与共享 | 成员与分享（成员 / 分享） | 合并「成员」+「分享」 |
| 外观与辅助 | 外观、通知、语音、浏览器 | 客户端偏好 |
| 高级（默认折叠） | 扩展（MCP / Hooks）、评测、网关、同步与备份 | 低频、专家向 |

合并理由：

- **用量 + 预算**：同一份花费数据的「查看」与「限制」，用户通常先看用量再设预算；合并后一个页面两个子页签，减少一次目录跳转。
- **子代理 + Skills + 提示词**：都是「agent 能力」的配置面，低频但相关；合并为「Agent 能力」，子页签保留原页面全部功能。
- **成员 + 分享**：都属于团队协作；分享链接的下文常是成员可见性，合并后同一个上下文。
- **MCP + Hooks**：都是「外部扩展/事件钩子」，专家向，合并为「扩展」并放进高级。
- 未合并的页面：主机、账号、权限、通知、语音、浏览器等有独立心智模型，合并会制造新层级。

### 3.2 顶栏：3 个会话图标 + 1 个侧栏开关

- 保留：侧栏开关（不计入会话操作）、改动审阅、信息面板。
- 新增「⋯ 更多」：后台任务、子代理（子菜单可直接跳转）、浏览器、文件、PR 与 CI、评测与轨迹、分屏（打开/布局/合并）。
- 移除：新会话页顶栏「派单」图标（侧栏已有唯一入口，命令面板仍可搜到）。
- 评测不再常驻；运行中的评测可从「更多」或命令面板进入。
- 结果：桌面会话顶栏 4 个图标（含侧栏开关），≤5；手机第一行 3 个 + 第二行 2 个，≤5。

### 3.3 命名与术语

统一规则写入 `docs/design.md`「术语表」：

- 用户界面用「主机」，代码/协议/日志仍用 Host。
- 实体统一「会话」；「对话」只描述消息内容。
- 统一「子代理」；层级称「子代理 / 孙代理」。
- 功能名统一「自动路由」；设置页同名。
- 团队协作实体统一「成员」。
- 保留 MCP、Hooks、Secrets、Skills、Worktree 等专有名词。

### 3.4 命令面板兜底

「更多」菜单中的每个入口都注册为命令：后台任务、子代理、浏览器、文件、PR 与 CI、评测与轨迹、分屏。设置页签与合并后的子页签继续由 `settingsRegistry` 覆盖。新增「新功能导览」「重新看上手引导」命令。

### 3.5 新功能导览

- 数据：`packages/web/src/lib/changelog.ts`，按版本组织，本轮 12 项。
- 版本升级后首次打开：右下角小卡「新功能 · 12 项」，点开为紧凑列表；每项一句话 + 「去看看」；「全部标为已读」写入 `tandem.changelogSeen.v1`。
- 目标为设置项时复用既有滚动+高亮；看板跳转后在侧栏入口加一圈高亮；分屏/搜索直接打开对应弹层。
- 首次安装（无主机且未完成引导）：同一位置显示 3 步上手引导（连接主机 → 添加账号 → 开始会话），可跳过；完成后视为已读。
- 设置页左下「关于 Tandem」可重新打开导览与上手引导。
