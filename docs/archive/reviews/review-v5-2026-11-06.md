# Tandem 内部体验评审 v5

评审对象：`packages/web` + `packages/server` · 视口 1440×900 / 390×844 · 浅色 / 深色
方法：真实 Host（3 账号、4 会话含 1 个 Task 子会话与 1 个 worktree 会话、真实 git 工作区、注入 MCP 错误态与 16 天用量数据）+ Playwright 截图与交互；桌面端通过注入 `window.tandemDesktop` 分别模拟 win32 / darwin。
基线：Claude Code Desktop / claude.ai；规范：`docs/design.md`。
本轮重点：MCP 设置与 MCP 工具卡、Task 子代理、worktree 会话、用量页、扫码配对、手机无 Host 页、桌面拖拽区；并回归新会话页、对话区、审阅面板、设置-账号。

## 结论

未发现阻断级 P0。共记录 27 条：P1 6 条、P2 21 条。已修复 23 条、部分修复 1 条，保留 3 条开放项。最影响精致度的是：worktree 会话在顶栏显示成 `cache`（把隔离目录当成项目名）、只监听回环时仍展示一张扫不通的二维码、用量图在手机上缩成约 5px 的文字且触屏无法查看每日数值、Windows 顶栏 48px 与 36px 高的原生窗口按钮错位；均已修复。

## 已验证的交互

- MCP：`filesystem`（不存在的 stdio 命令）与 `github`（不可达 HTTP）均显示「出错」+ ENOENT/fetch failed；展开可见错误，刷新才重连；删除弹确认。
- Task：主会话 Task 卡内嵌子会话消息流（子代理任务/Glob/Grep/最终汇报）、状态「已结束」，运行中显示停止按钮；审批卡来源标注代码路径正常。
- worktree：新会话可开启隔离分支、自动分支名；侧栏与主仓库同组；合并弹窗可选 Merge/Squash；有未跟踪文件时删除返回 409 并出现「仍然删除」二次确认。
- 用量：7 天/30 天/本月切换，汇总卡与按模型/账号/Host 排行，未知单价模型仍计 token；账号单价覆盖入口在账号编辑的模型步骤。
- 配对：回环时只显示不可用说明与重试；非回环时才出二维码；手机无 Host 页含粘贴链接、手动地址/Token、扫码/系统相机提示。
- 桌面：win32 右侧 140px 留空 + 36px 顶栏；darwin 侧栏 logo 72px 左留白；顶栏按钮在 drag 区内可点。
- 回归：新会话页、对话区贴底与工具卡、审阅面板文件/diff/提交区、账号列表与编辑向导；浅/深色 390px / 1440px 无页面级横向溢出，控制台无意外 error（仅 409 请求的预期资源错误）。
