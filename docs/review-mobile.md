# 手机端专项走查（2026-11-07）

范围：安卓/手机浏览器共用的一份 web（Capacitor 打包）。此前只做过布局适配，本轮按手机主路径逐页真实触摸走查，修复 P0/P1 与易修 P2。

## 走查环境与方法

- 临时 Host：`TANDEM_HOME=/tmp/tandem-mob`，端口 8251；独立 `HOME`，不读真实 `~/.claude`、`~/.codex`。
- 造数：2 个账号（含分组、长名称）、6 个会话（30 轮长会话、工具调用、diff、待审批、计划模式、预算告警、归档）、预算规则、定时任务、权限规则、用量。
- Playwright：Pixel 7（412×915）与 360×780 小屏；`isMobile` + `hasTouch`；深色/浅色各一轮。
- 每页真实点击/触摸：首页/收件箱、侧栏抽屉（滑动关闭）、会话页（长按消息、轮次抽屉、工具卡、文件预览、改动审阅）、输入框“更多”菜单、模型菜单、环境条、派单、设置各页、反馈模式。
- 额外模拟软键盘：把视口高度压到 52%，检查输入框是否被遮挡；弹层统一检查是否越出屏幕。
- 截图在 `/tmp/mob/`（临时目录，清理后不保留）。

## 遗留（未改，记录在案）

1. **设置页 20 个页签占满半屏**：手机端设置导航为三列网格，进入后内容区只剩约 300px。可用，但信息密度高；建议后续改成“当前页签 + 下拉切换”，涉及现有回归用例「三列导航」，需要产品确认。
2. **内联文件链接**：消息里的路径链接本身 20px 高（正文内联元素），未强制 44px；点按可打开预览，已有独立回归。
3. **Assistant 长按**：为避免与文本选择冲突，只对用户消息做了长按；assistant 仍用右下角 44px“⋯”。如需统一，可再做。
4. **diff 行号/符号 11px**：等宽 diff 槽位属于紧凑标记，保持 11px 以控制行宽；如需严格 12px 需同步调整行号列宽。
5. 未在真实安卓机/软键盘上验证（Playwright 仅模拟视口收缩）；iOS 安全区逻辑沿用现有 `env(safe-area-inset-*)`。
