# 模型路由：自动路由 + 分工路由

> 更新：2026-11-10。**主会话模型恒定，执行交给 Task 子代理**：prompt 缓存按模型/服务商命中，来回换模型会让整段上下文按未命中价重发。按难度自动选模型另见 `architecture.md` 的 `model-routing.ts` 与设置「模型路由」。

## 三种模式

| 模式 | 谁执行 | 何时 |
|---|---|---|
| 单代理（默认） | 主会话模型自己完成 | 对话、问答、解释代码、小改动、需大量上下文判断的修改、调试分析、架构/评审 |
| 低成本 | 主会话不调用；用户消息直接交给便宜执行者子代理，摘要回主会话 | 一眼机械且自包含：跑命令、装依赖、格式化、lint/test、重命名、样板 |
| 多代理协作 | 主会话先只读定位并拆解，用 Task 派自包含子任务给执行者/专长执行者，摘要回规划者 | 多步且可独立执行的机械子任务；或领域专长匹配且复杂度 ≥ 门槛 |

分类由规则完成（关键词、长度、领域、预算、历史失败），不额外调用模型；结果是一行提示，用户可覆盖。覆盖优先级：用户 > 会话偏好 > 规则。

**不分工硬清单**：纯对话/问答/解释/比较；需大量上下文判断的修改；小改动（改名/文案/样式/单文件小编辑）；用户说「你直接做/不要派子代理」；委派倾向「关闭」或执行者/预算不可用；预计收益小于子代理启动与摘要开销。

**失败升级**：低成本失败 → 本轮主模型直接处理并提示；多代理执行者连续失败 2 次 → 规划者接管或换专长模型，禁止无限重试。

## 机制

- 主会话 = 规划者（用户当前模型），上下文与缓存只属于它，**不切换**。
- 执行用现有 `Task`，角色 `executor|specialist`（可带 `domain`）；服务端从分工设置解析账号/分组/模型，创建子会话。
- 子代理只收到任务描述、必要路径、验收命令、约束，不继承主会话历史；完成后只回传最后一段摘要。
- 规划者系统提示（仅分工模式/本轮）：先只读定位、写 2–5 步计划；Task prompt 自包含；一两步能做完的自己改；前端 UI 可派 specialist，其余机械步骤派 executor。
- 领域 `ui|backend|test|docs|data|ops|general` 由规则推断；领域→模型映射在设置维护，带专长说明与最低复杂度。

## 成本结论

同会话切模型一轮 ≈ `2C·P + C·p`；子代理分工 ≈ `C·P + c·p + C·P·cache`（`c << C`）。以 C=100k、c=10k、P=$3/M、p=$0.3/M、缓存 90% 估算：切换 ≈ $0.63，子代理 ≈ $0.333，约省 47%。上下文越大、步骤越多差距越大；子代理有摘要输出开销，规则只在机械子任务足够大时分工。

## 数据与协议

- 会话：`routePreference?: 'auto' | 'direct' | 'cheap' | 'division'`；存在即按规则/固定模式规划，`auto` 表示按规则（旧会话的 `routeMode: 'division'` 读取时迁移为 `routePreference: 'auto'`）。
- `ModelRoutingSettings.division`：规划/执行/审查绑定、`domains[]`、`planThreshold`（默认 55）、`costCapUsdPerTurn`（缺省关闭）。
- `Message.routePlan`：模式、理由、领域、执行者/专长模型；`ModelRouteDecision.role/domain/specialist`；`UsageStatsRow.role/routeSavedUsd`。
- Task 输入新增 `role/domain`，`ToolContext.runSubagent` 透传。

## 界面

1. 模型菜单只列模型（含自动路由）；执行方式在输入框底栏选择。
2. 输入框底栏唯一「执行方式」：自动 / 单代理 / 低成本 / 多代理协作；子菜单「委派倾向」：仅规划 / 积极 / 适度 / 关闭；可「记住为会话偏好」。
3. 每个任务一行提示（模式 · 理由/领域/复杂度），右侧覆盖按钮；Composer 可对下一条消息一次性覆盖。
4. 设置 →「模型路由」：角色绑定、领域映射、分工阈值、每轮成本上限、预算紧张禁用专长、三套预设（省钱/质量/前端专项）。
5. 用量按角色统计调用/花费/节省；右栏会话用量显示角色拆分。

**人工确认**：设置「多代理协作前确认」（从不 / 仅贵时 / 总是，默认仅贵时）；需要时消息流出现紧凑计划卡（子任务、模型、预计花费），可换模型/删子任务/改单代理或低成本，确认后才派发，同时写收件箱。运行中可「换模型重跑」或「交回主会话」。学习偏好按领域+机械动作累计，同类 ≥2 次后只自动采纳「单代理」。

## 价格与倍率

内置官方参考价（Claude、GPT-4o/4.1/5/6、o 系列、DeepSeek、Gemini、Kimi/Moonshot、Qwen、GLM，按前缀匹配，表头注明参考日期）。实际价 = 官方价 × 账号倍率 × 分组倍率；账号按模型覆盖单价优先，覆盖价不乘倍率。计费、压缩、网关、Wiki、评测与菜单展示共用 `resolvePriceForModel` / `priceForModel`；菜单 tooltip 显示计算式，无参考价显示「无参考价 · 去设置」；历史花费不重算。

## 思考强度

`packages/server/src/providers/capabilities.ts` 是唯一能力表：按模型 id 推断档位、厂商叫法与参数映射；provider 返回能力优先，账号/分组可覆盖。OpenAI 走 `reasoning_effort`（o 系列 low/medium/high，gpt-5/6 含 minimal）；Anthropic 走 `budget_tokens`（2K/8K/16K/32K）；Grok/Gemini/DeepSeek 按各自 API；不支持思考返回空数组，菜单隐藏该项。芯片只显示模型名，强度只在菜单/tooltip/aria-label。

## 入口收敛与子代理

- 入口两层：输入框「执行方式」、其子菜单「委派倾向」。环境条只放主机/文件夹/分支/设备胶囊；Task 是内部机制，不单独做入口。
- 文案集中在 `packages/web/src/lib/routeLabels.ts`，执行方式用「自动 / 单代理 / 低成本 / 多代理协作」，委派倾向用「仅规划 / 积极 / 适度 / 关闭」。
- 子代理层级统一叫「子代理」，12px 缩进+引导线，最多 6 层再深显示 `L8`；Task 卡片一行标题、提示词第二行省略；点击卡片/代理树/顶栏进入只读子会话，面包屑逐层返回，复用 `MessageList` + `TurnRail`，无输入框。
