# 自建 Key 网关（可选，默认关闭）

> 更新：2026-11-10。团队成员的模型请求经一台 Tandem Host 统一转发：网关替换真实 Key、限流、记账、写脱敏日志。**只在可信内网使用**，HTTP 明文，禁止端口映射/公网反向代理。

## 是什么

成员只拿网关令牌（`tgw_…`），不接触上游 Key；团队共享账号与多 Key 分组，复用 failover/round-robin/冷却；成本按「成员 × 模型 × 天」记账并进入用量与预算。

## 架构

```
成员客户端（账号类型：Tandem 网关，地址=网关 Host，Key=tgw_…）
  │ POST /gateway/v1/chat/completions（OpenAI 兼容）
  │ POST /gateway/v1/messages（Anthropic 兼容）
  ▼
网关 Host（设置 → 网关）
  ├─ 令牌鉴权（team.json 成员；gateway.json 只存 SHA-256）
  ├─ 成员限额、RPM 滑动窗口、模型白名单
  ├─ model → 本机 Profile › Group；Key 轮换/冷却
  ├─ 预算（账号/分组/模型/全局 block）
  ├─ 转发：替换 Authorization / x-api-key，透传 SSE/JSON
  └─ 记账：usage.json（memberId）+ gateway.json（元数据）
```

协议必须匹配：OpenAI 入口只路由 OpenAI 兼容分组，Anthropic 入口只路由 Anthropic 分组；不跨协议翻译，不匹配返回 409。

## 怎么用

1. 网关 Host 的「账号与模型」添加上游账号/分组。
2. 「设置 → 网关」开启，添加模型路由（模型名 → 账号 › 分组）。
3. 「设置 → 成员」邀请同事；在「网关」签发令牌，设置每日/每月限额、RPM、模型白名单。明文只显示一次。
4. 成员在自己 Host「账号与模型 → 新建账号」选「Tandem 网关」，填网关地址与 `tgw_…`，拉取模型后保存。

## 鉴权、限额与限流

- 令牌 `tgw_` + 64 位十六进制；Host 只存 SHA-256（`gateway.json` 600、原子写）。重新签发会轮换，旧令牌立即失效；成员吊销后令牌同时失效。
- 每日/每月限额按美元累计（参考价同用量页），达到上限返回 429；RPM 为内存滑动窗口（每令牌每分钟），超限 429 + `Retry-After`。
- 模型白名单为空表示全部路由模型；网关请求同时受现有预算规则拦截。
- 记账在响应完成后写入：并发请求结算前可能短暂超过限额一个请求的额度。

## 日志与调试正文

- 默认 `gateway.json` 环形数组最近 1000 条：时间、成员、模型、协议、token、花费、耗时、状态码、是否流式、路由、错误摘要；**不记录正文、Header、Key、IP**。
- 调试正文默认关闭；开启后写 `gateway-debug.json`（600，最多 200 条、单条 200KB），自动脱敏 `authorization`/`api_key`/`token`/`secret`/`password`/`cookie` 与 `Bearer`/`sk-`/`tgw_`/`tmm_` 形态，24h TTL，关闭即清空；不通过 REST 暴露。

## 默认值

| 项 | 默认 |
|---|---|
| 网关模式 / 模型路由 | 关闭 / 空 |
| 调试正文 | 关闭，TTL 24h |
| 令牌 RPM | 60 |
| 每日/每月限额 | 不限 |
| 模型白名单 | 空 = 全部路由模型 |
| 日志保留 | 最近 1000 条元数据 |
| 端口 | 与 Host 相同（默认 8270 / `--port`） |

## 威胁模型与限制

- 令牌泄露 = 可冒用该成员额度与白名单；立即吊销/轮换。令牌不含上游 Key，无法直连上游。
- 明文 HTTP：同网段可截获令牌与正文；只在可信内网/VPN，防火墙限制来源。禁止公网暴露。
- 恶意成员受 RPM、限额、白名单约束，不能改路由/账号/Key 或看他人额度。
- 无 TLS / 请求签名 / 小时级限流；协议不跨转；未知模型记 0 花费只统 token；调试正文仅本机文件。
- 不部署公网、不接第三方推送/云服务。
