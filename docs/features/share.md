# 会话只读分享（内网）

> 更新：2026-11-09。

把一个会话以只读链接发给同一局域网内的同事，不暴露 Host 主 token、模型 Key、环境变量与（默认）绝对路径。分享由 Host 自己提供页面，不接任何第三方服务，也不对公网开放。

## 使用

1. Host 必须以局域网可达地址监听：`tandem-host --host 0.0.0.0 --port 7878`。只监听 `127.0.0.1` 时，创建分享会返回提示，链接只能在本机打开。
2. 会话列表 ⋯ 菜单 →「分享…」→ 选择有效期 / 是否含工具输出 / 是否隐藏路径 / 快照或实时 →「生成链接」。
3. 把链接（或二维码）发给同事。链接形如 `http://192.168.1.5:7878/s/<shareId>#<token>`。
4. 设置 →「分享」查看全部分享的会话、创建时间、有效期、访问次数，并可随时撤销。撤销后公开接口立即 404。

## 默认值与行为

| 选项 | 默认 | 说明 |
|---|---|---|
| 有效期 | 7 天 | 可选 1 小时 / 1 天 / 7 天 / 不过期（手动撤销） |
| 隐藏路径 | 开 | `cwd` 下的路径变成相对路径，home 变 `<home>`，其余绝对路径变 `<path>/文件名` |
| 包含工具输出 | 开 | 关闭后工具结果只保留首行摘要 |
| 冻结快照 | 关 | 关 = 实时：分享页每 3 秒轮询；开 = 创建时快照 |

- 分享 token 为 32 字节随机值，位于 URL fragment（`#` 后），浏览器不会把 fragment 发给服务器，因此不进访问日志；Host 只保存 SHA-256 哈希。
- 公开数据接口：`GET /api/public/shares/:id`，请求头 `Authorization: Share <token>`。不需要 Host 主 token，且只能读出该会话的脱敏副本。
- 管理接口（`POST /api/sessions/:id/shares`、`GET /api/shares`、`DELETE /api/shares/:id`）仍需要 Host 主 token。
- 访问次数与最后访问时间会记录；IP 只在本机进程内存保留最近 20 条，不落盘。
- 会话被删除后，其分享也立即 404。

## 脱敏范围

- 始终移除：各类 API Key / token 字面量、`Authorization` 头、URL query / JSON / 环境变量形式的凭据、URL 中的 `user:pass@`、私钥块、当前进程敏感环境变量的值。
- 不返回：账号 ID / 分组 / 模型 Key、`cwd`、Host 环境信息、预算与权限规则。
- 工具输出按选项保留或摘要；用户主动发送的截图（image block）会保留。

## 威胁模型

| 风险 | 缓解 |
|---|---|
| 链接被转发到公开群 / 截图泄露 | 链接自带随机 token，可随时撤销；默认 7 天过期；页面提示“请勿转发到公网”。 |
| 路径泄露主机目录结构 | 默认隐藏绝对路径；关闭该选项时有明显提示。 |
| 实时模式让同事看到后续内容 | 默认实时仅影响该会话后续消息；不想继续暴露时改用快照或撤销。 |
| token 进入日志 | token 只在 fragment 与 `Authorization: Share` 头中；Host 访问日志不记录 header 与 fragment。 |
| 枚举 shareId | shareId 为 UUID，且必须同时持有 token；缺失/错误 token 与不存在统一返回 404。 |
| 公网暴露 | 产品约束：不部署公网、不接第三方；只在可信内网使用。Host 监听 `0.0.0.0` 时同网段人均可访问端口，需自行确认网络可信。 |

## 已知边界

- 实时模式用轮询（3 秒）而非 WebSocket，避免公开端点扩大 WS 鉴权面。
- 快照保存在 `~/.tandem/shares/<shareId>.json`（600 权限），删除分享时一并删除。
- 分享页不提供搜索、输入、审批或任何写操作；仅渲染消息列表。
