# 输入框（Composer）

> 更新：2026-11-11。分工、取向与原生开关的完整路由规则见 [routing.md](routing.md)；本页只写输入框自身的交互。

## 1. 发送与分工取向

- **Enter 发送**（手机为换行）、**Shift+Enter 换行**、**Ctrl/Cmd+Enter 发送**。
- 分工与取向在模型菜单（输入框底栏模型芯片点开）的底部分组里：最上「原生」可勾选项，下面「分工」（关闭 / 适度 / 积极）与「取向」（省钱 / 均衡 / 质量优先）各一组单选。选择立即写入当前会话，后续所有消息都用这组设置，没有「记住为会话偏好」；原生打开时分工与取向置灰并注明「原生模式下不生效」。模型芯片只显示模型名。入口合并原因见 [routing.md](routing.md)。
- 环境条只有主机 / 文件夹 / 分支 / Worktree（分支与 Worktree 仅 git 仓库显示）；在新会话页的环境条选择目标主机即可在任意主机上开会话。
- 新会话页的账号、分组、模型与思考强度按主机记住（`lib/newSessionPick.ts`，本机 localStorage）：选择即写入，换回该主机或刷新后恢复；记住的账号/分组/模型已不存在时回落到默认选择，不报错。思考强度只记用户主动选择的值，模型不支持时的自动降档只作用于本次显示与发送。
- 新会话页发送后直接进入会话：创建请求返回前先显示占位会话（id 以 `draft-` 开头）与用户消息，占位会话不发起其它请求、不发往 Host；创建失败时回到新会话页并提示。

## 2. Markdown 实时预览（CodeMirror，反馈8#02 / 1323#05）

输入框是 Markdown 源码编辑器：发送内容就是原始文本。编辑面由 CodeMirror 6 承载（文本、撤销、选区、输入法与光标），展示层只生成装饰，不改文本。

- **光标行显示源码**：光标（或选区）所在行显示原始 Markdown，标记符淡化可见；代码块、表格以整个块为范围——光标在块内时整块显示源码。
- **其余行按渲染样式显示**：隐藏 `#`、`**`、`*`、反引号、`[标签](url)` 的括号与 URL；标题加粗放大，列表显示圆点/序号并悬挂缩进，引用显示左竖线，粗体/斜体/行内代码/链接直接呈现，分割线显示为细线。
- **代码块**：光标在块内时整块显示源码（等宽 + 浅色底）；光标在块外时整块渲染成与消息区一致的代码块卡片（同样的 `chat-code` 底色与圆角，无头部工具条），点击卡片回到源码。输入框不做语法高亮。
- **表格**：与代码块一样整块切换；光标在块外时渲染成消息区样式的表格（表头、行分隔线、内部横向滚动），点击回到源码。
- **键盘**：Enter 发送、Shift+Enter 换行；`1.`/`-` 回车续号/续项、空列表项回车结束列表；代码块内 Enter 只换行、Tab 插入两个空格；开围栏行回车自动补闭合围栏；`Ctrl/Cmd+Enter` 始终发送。
- **输入法**：组合期间不重算装饰、不触发补全，Enter 只确认候选不发送；组合结束按最终文本判断。
- **拼写检查**：编辑面关闭原生拼写检查、自动纠正与自动填充。
- 实现：`components/composer/ComposerEditor.tsx`（CodeMirror 宿主与外部句柄：聚焦、选区、受控文本同步）、`markdownLive.ts`（StateField 装饰：标记隐藏与样式、代码块/表格整块卡片、@ 路径原子范围）、`richEditor.ts`（@ 路径标记识别）、`markdownInput.ts`（回车/Tab 文本变换）；样式在 `styles/chat.css` 的 `.composer-cm` / `md-*`。

## 2.1 @ 文件与文件夹（反馈2102#07）

- `@` 补全同时列出文件与文件夹；文件夹带文件夹图标，并标「→ 进入」。
- 文件夹上按 `→` 进入该目录继续浏览，补全不关闭；`Enter` / 点击则直接把该文件夹作为路径标记插入。
- 选中后输入框里是一个不可拆分标记，只显示文件名/文件夹名，悬停显示完整路径；退格或 Delete 整块删除。
- 发送时按原样带上完整相对路径（与原先插入格式一致）；标记只是显示层的缩写，只有本次补全选中的路径会识别为标记。
- 实现：`richEditor.ts` 的路径标记识别（`ce-path`，中性胶囊：`--t-bg-subtle` 底 + `--t-border` 描边 + `--t-text-secondary` 文字）、CodeMirror 的 atomic range + widget（整块移动/删除，组合输入期间不套样式）、补全项 `isDir`（`CompletionEntry`）、Host 的 `/api/fs/complete` 同时遍历目录并以 `/` 结尾返回。

## 3. 输入 token 估算（反馈8#05）

- 底栏在输入非空时显示 `~x tok`，并显示发送后的上下文占比 `发送后 ~y%`（有上下文上限数据时）。
- 估算口径与 Host 一致：文本 `ceil(字符数 / 3.5)`；图片每张 1200 token；计入粘贴折叠文本与「已选元素」上下文。当前上下文取会话摘要的 `context.usedTokens`，上限取 `context.contextWindow`；新会话没有当前上下文占用，只按本次输入 / 模型上限给占比；没有上限数据时只显示输入 token。
- 数字前一律带 `~`，tooltip 写出本次输入、发送后总量/上限；不是精确计费。

## 4. 切换模型/账号/分组的缓存确认（反馈8#08 / 反馈10#02）

- 模型菜单不显示常驻提示；确认框只有「切换 / 取消」两个动作。
- 会话已有上下文（`context.usedTokens > 0`）且用户选中了不同的模型 / 账号 / 分组 / 自动路由时，弹出统一确认框（`ui/ConfirmAction`）：标题「切换后提示缓存将失效」，说明「下一轮按完整上下文计费」，并显示 `约 ~x tok / $x`。
- 费用按目标模型的实际输入单价估算（账号/分组倍率已生效）；目标账号/分组的价格尚未加载或模型没有参考价时只显示 token；极小金额显示 `< $0.0001`，不显示 `$0.0000`。
- 「取消」保持原模型，「切换」才写入会话；只是重新选中当前模型不弹框。思考强度是请求参数、不改变缓存前缀，不提示；改系统提示（记忆文件等）会改变前缀，属于另一个入口，暂不在此估算。

## 5. 有待审批时发送 = 拒绝并说明（反馈14#07）

- 审批是对话流里的一条消息，输入框保持可用；有待审批时发送消息，先对当前审批项发 `deny`（理由取发送内容），再照常发送这条消息。见 [conversation.md](conversation.md) 的「审批请求内联在对话流」。

## 6. 环境条：会话内换主机（反馈13#02 / 反馈14#04 / R50 / R31）

- 在会话的环境条里选另一台主机**不会立即切换**。主机下拉里当前主机行尾标「当前」，目标主机行尾标「待切换」（中性小字，不抢选中态）。
- 环境条主机胶囊只显示目标主机名；胶囊右侧一个撤销图标（tooltip「取消切换」）。文件夹胶囊只写「待选」，用中性强调（不用警告色），并自动打开**新主机**的文件夹选择器。
- 选好文件夹后才执行导出 → 目标主机导入 → 跳转到新会话；迁移失败时保留待选状态，方便重新选目录。换会话或换主机时自动清掉待选状态。
- 待选期间**输入框整体变暗锁定**（`composer-card[data-disabled]`，不可输入），提示只写在占位符里：「选择 <新主机> 上的文件夹后继续」。
- 文案保持精简、不口语化。
- 回归：`e2e/regression.mjs`「环境条换主机先选文件夹：待定状态、输入禁用、可取消（反馈13#02）」。

## 7. 环境条：透明行、非 Git 仓库与文件夹入口（反馈1323#06–#09）

- 环境条行与根节点保持透明，只有触发器在悬停/展开时给自身底色（反馈1323#06）。
- 目录不是 git 仓库时不渲染分支触发器，也不渲染 Worktree 开关；主机与文件夹仍在。git 仓库保持原样（反馈1323#07 #08）。
- 文件夹弹层只列该主机的最近目录（`loadRecentDirs`，最多 8 条，无记录时不显示「最近」分组）和底部「打开文件夹…」；无最近记录时只有这一项。分组标题、分隔线与行都走 `ui/Menu`（`Menu.Label` / `Menu.Separator` / `Menu.Item`），内边距 4px、行高 26px、标题 12px 与其他下拉一致；ui-audit 检查弹层里不再手写标题/分隔线（反馈1601#01 / R01）。
- 「打开文件夹…」的两种去向：
  - **桌面版且所选主机就是本机** → 系统文件夹对话框（preload `folder.pick` → 主进程 `folder:pick`）。
  - **其他情况**（网页、手机、远程主机、WSL 里的 Host 与 Windows 客户端不是同一文件系统）→ 应用内「打开文件夹」对话框，里面复用 `FolderBrowser` 目录浏览器。
- 本机判定：`window.tandemDesktop.isDesktop === true` 且所选主机的 `HostInfo.id` 等于桌面内置工作站的本地主机上下文 hostId（主进程 `host:local-id`）；任一信息缺失按非本机处理。实现见 `lib/desktopFolder.ts`，单测 `desktopFolder.test.ts`。
- 回归（`e2e/regression.mjs`）：「环境条容器透明、触发器可见且不越界」「环境条文件夹弹层只列最近文件夹与「打开文件夹…」（反馈1323#09）」「非 Git 仓库时不显示 Worktree 开关（反馈1323#07）」「非 Git 仓库时不显示分支触发器（反馈1323#08）」「文件夹弹层沿用 ui/Menu 的边距与行高（反馈1601#01）」。

## 8. 验证

- 单测：`packages/web/src/components/composer/markdownInput.test.ts`（围栏成对、代码块 Enter/Tab、列表续号/续项/退出、token 估算）、`richEditor.test.ts`（@ 路径标记识别与整块删除）。
- 回归（`e2e/regression.mjs`）：
  - 「输入框：token 估算、切换确认与分工取向合并」：模型菜单含原生/分工/取向且没有「记住为会话偏好」、模型芯片只显示模型名、输入 token 与发送后占比；切换时弹确认框、取消不改模型、确认后切换；思考强度在菜单与 tooltip / aria-label 里（反馈14#03 / 1601#04）。
  - 「输入框 Markdown 实时预览：光标外隐藏标记、代码块整块渲染、Enter 续号与原始内容发送（反馈8#02 / 1323#05）」：光标外不显示 `#`/`**`、移入后显示源码；代码块卡片无工具条、点击回源码；行内代码/粗斜体、列表圆点与序号、续号、空列表项结束、输入法组合期间不发送、原始 Markdown 发送。
  - 「用户气泡完整渲染 Markdown：标题降级、列表、代码块与源码编辑」：气泡内标题/列表/代码块/粗体已渲染、无源码标记；编辑时回到原始 Markdown；发送内容等于源码。
  - 「输入框 @ 选文件与文件夹：文件夹可进入、路径标记只显示名字、发送仍是完整路径（反馈2102#07）」：文件夹图标、→ 进入、标记只显示名字与悬停完整路径、发送带完整路径。
