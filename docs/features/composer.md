# 输入框（Composer）

> 更新：2026-11-11。分工与取向的完整路由规则见 [routing.md](routing.md)；本页只写输入框自身的交互。

## 1. 发送与分工取向

- **Enter 发送**（手机为换行）、**Shift+Enter 换行**、**Ctrl/Cmd+Enter 发送**。
- 输入框底栏唯一的「分工与取向」菜单：分工（关闭 / 适度 / 积极）与取向（省钱 / 均衡 / 质量优先）各一组单选，下方「记住为会话偏好」。选择只作用于下一条消息；勾选记住后两个维度都写入会话。入口收敛原因见 [routing.md](routing.md)。
- 环境条只有主机 / 文件夹 / 分支 / Worktree（分支与 Worktree 仅 git 仓库显示）；在新会话页的环境条选择目标主机即可在任意主机上开会话。
- 新会话页的账号、分组、模型与思考强度按主机记住（`lib/newSessionPick.ts`，本机 localStorage）：选择即写入，换回该主机或刷新后恢复；记住的账号/分组/模型已不存在时回落到默认选择，不报错。思考强度只记用户主动选择的值，模型不支持时的自动降档只作用于本次显示与发送。
- 新会话页发送后直接进入会话：创建请求返回前先显示占位会话（id 以 `draft-` 开头）与用户消息，占位会话不发起其它请求、不发往 Host；创建失败时回到新会话页并提示。

## 2. Markdown 输入（反馈8#02）

输入框保持纯文本编辑，发送内容就是原始 Markdown；不做所见即所得。

- **代码围栏**：在行首输入 ```` ``` ```` 或 ```` ```lang ```` 后回车，自动补一个空行和同缩进的闭合围栏，光标停在中间；代码块内回车只换行、不发送；Tab 插入两个空格。闭合围栏行回车后在围栏后新起一行。
- **列表**：`1. ` / `1) ` 回车自动续号（保留缩进与标点）；`- ` / `* ` / `+ ` 回车自动续项；`- [ ]` 任务列表续项时保留未勾选框；空列表项回车退出列表。列表项末尾回车用于续项，不会直接发送。
- **标题 / 分割线 / 引用**：`#`~`######`、`---`/`***`/`___`、`>` 只做轻量着色；普通行回车仍发送。
- **着色层**：textarea 文字透明，背后一层同字号/行高/字体的 `<pre>` 着色（代码围栏、代码行、列表标记、标题、行内代码、链接、粗斜体）。只改颜色、不改字重/字号/字距，保证光标与换行对齐；输入法组合期间临时隐藏着色层、显示原始文字。
- 实现：`components/composer/markdownInput.ts`（纯文本变换，单测 `markdownInput.test.ts`）、`MarkdownHighlight.tsx`（着色），样式在 `styles/chat.css` 的 `composer-editor` / `md-hl-*`。

## 3. 输入 token 估算（反馈8#05）

- 底栏在输入非空时显示 `~x tok`，并显示发送后的上下文占比 `发送后 ~y%`（有上下文上限数据时）。
- 估算口径与 Host 一致：文本 `ceil(字符数 / 3.5)`；图片每张 1200 token；计入粘贴折叠文本与「已选元素」上下文。当前上下文取会话摘要的 `context.usedTokens`，上限取 `context.contextWindow`；新会话没有当前上下文占用，只按本次输入 / 模型上限给占比；没有上限数据时只显示输入 token。
- 数字前一律带 `~`，tooltip 写出本次输入、发送后总量/上限；不是精确计费。

## 4. 切换模型/账号/分组的缓存确认（反馈8#08 / 反馈10#02）

- 模型菜单不显示常驻提示；确认框只有「切换 / 取消」两个动作。
- 会话已有上下文（`context.usedTokens > 0`）且用户选中了不同的模型 / 账号 / 分组 / 自动路由时，弹出统一确认框（`ui/ConfirmAction`）：标题「切换后提示缓存将失效」，说明「下一轮按完整上下文计费」，并显示 `约 ~x tok / $x`。
- 费用按目标模型的实际输入单价估算（账号/分组倍率已生效）；目标账号/分组的价格尚未加载或模型没有参考价时只显示 token；极小金额显示 `< $0.0001`，不显示 `$0.0000`。
- 「取消」保持原模型，「切换」才写入会话；只是重新选中当前模型不弹框。思考强度是请求参数、不改变缓存前缀，不提示；改系统提示（记忆文件等）会改变前缀，属于另一个入口，暂不在此估算。

## 5. 有待审批时发送 = 拒绝并说明（反馈14#07）

- 审批是对话流里的一条消息，输入框保持可用；有待审批时发送消息，先对当前审批项发 `deny`（理由取发送内容），再照常发送这条消息。见 [conversation.md](conversation.md) 的「审批请求内联在对话流」。

## 6. 环境条：会话内换主机（反馈13#02 / 反馈14#04 / R50 / R31）

- 在会话的环境条里选另一台主机**不会立即切换**。主机下拉里当前主机行尾标「当前」，目标主机行尾标「待切换」（中性小字，不抢选中态）。
- 环境条主机胶囊只显示目标主机名；胶囊右侧一个撤销图标（tooltip「取消切换」）。文件夹胶囊只写「待选」，用中性强调（不用警告色），并自动打开**新主机**的文件夹选择器。
- 选好文件夹后才执行导出 → 目标主机导入 → 跳转到新会话；迁移失败时保留待选状态，方便重新选目录。换会话或换主机时自动清掉待选状态。
- 待选期间**输入框整体变暗锁定**（`composer-card[data-disabled]`，不可输入），提示只写在占位符里：「选择 <新主机> 上的文件夹后继续」。
- 文案保持精简、不口语化。
- 回归：`e2e/regression.mjs`「环境条换主机先选文件夹：待定状态、输入禁用、可取消（反馈13#02）」。

## 7. 环境条：透明行、非 Git 仓库与文件夹入口（反馈1323#06–#09）

- 环境条行与根节点保持透明，只有触发器在悬停/展开时给自身底色（反馈1323#06）。
- 目录不是 git 仓库时不渲染分支触发器，也不渲染 Worktree 开关；主机与文件夹仍在。git 仓库保持原样（反馈1323#07 #08）。
- 文件夹弹层只列该主机的最近目录（`loadRecentDirs`，最多 8 条，无记录时不显示「最近」分组）和底部「打开文件夹…」；无最近记录时只有这一项。
- 「打开文件夹…」的两种去向：
  - **桌面版且所选主机就是本机** → 系统文件夹对话框（preload `folder.pick` → 主进程 `folder:pick`）。
  - **其他情况**（网页、手机、远程主机、WSL 里的 Host 与 Windows 客户端不是同一文件系统）→ 应用内「打开文件夹」对话框，里面复用 `FolderBrowser` 目录浏览器。
- 本机判定：`window.tandemDesktop.isDesktop === true` 且所选主机的 `HostInfo.id`（Host 配置里的 hostId）等于桌面内嵌 Host 的 hostId（主进程 `host:local-id`）；任一信息缺失按非本机处理。实现见 `lib/desktopFolder.ts`，单测 `desktopFolder.test.ts`。
- 回归（`e2e/regression.mjs`）：「环境条容器透明、触发器可见且不越界」「环境条文件夹弹层只列最近文件夹与「打开文件夹…」（反馈1323#09）」「非 Git 仓库时不显示 Worktree 开关（反馈1323#07）」「非 Git 仓库时不显示分支触发器（反馈1323#08）」。
