# 会话树（侧栏会话行、悬停拓扑图、切分支）

> 更新：2026-11-12。用户 2026-11-11 22:09 与 2026-11-12 的原话决定了侧栏会话行的几件事，单点断言在 `scripts/decisions-check.mjs` 的 `sidebar-fork-same-row`、`sidebar-hover-topology`、`sidebar-old-sessions-collapsed`、`graph-trunk-current`。绘制规范、颜色与高度见 [session-graph.md](session-graph.md)。

## 一行一棵会话树

- 分叉不新增侧栏行，与根会话共用一行；行标题始终是根会话标题（用户原话「以后分叉就不要新增一个会话选项卡了，跟原来的会话共用一个选项卡」）。
- 点击该行打开树内**最近活动**的会话（主会话或某个分叉）；当前打开的是分叉时，行内标题后用 12px 次要文字标出所在分叉名（`data-session-branch`）。
- 未读、运行中、待审批按树内任一会话汇总；汇总优先级：待审批 → 运行中 → 等待网络 → 错误 → 空闲。
- 置顶按整棵树生效：行出现在置顶区时，取消置顶会取消树内所有会话的置顶，避免分叉留在置顶区。
- 子代理/孙代理仍不进侧栏；根会话已归档而分叉未归档时，分叉退回独立一行，不会消失。会话树的归并口径在 `lib/sessionTree.ts`（分叉跟 `forkedFrom`、子代理跟 `parentId` 向上找根）。

## 更早的会话默认收起（反馈1603#01）

- 项目分组里最近活动超过 7 天的会话默认不渲染，组末一行「更早的 N 个会话」（次要文字行，带折叠箭头）；点开才加载并展开，再点收起。阈值常量 `OLDER_SESSION_MS`（7 天）。
- 固定（项目内固定）、运行中、待审批、等待网络、未读的会话不受影响，始终显示。
- 展开状态按项目记在本机（`expandedOlderProjects`，键与折叠记忆同源：主机 + 仓库根路径），换会话或刷新后保持；搜索与「已归档」视图不收起。

## 悬停拓扑图

- 悬停任一会话行，在行右侧弹出浮层；悬停延迟与标准 tooltip 相同（500ms 弹出、300ms 收起，常量共用 `Tip` 的 `TIP_SHOW_DELAY`/`TIP_SKIP_DELAY`），移入浮层不消失，`Esc`、点击、移出后收起。
- **树里只有当前会话（没有分叉、没有子代理）时不弹**（用户 2026-11-12 原话：这个卡片没有什么用，反馈0220#06）。
- 浮层与右栏会话图是**同一张图**（同一个 `layoutSessionGraph` 与 `SessionGraphView`），只是紧凑模式：不显示轮次标题，只在每个会话起点显示会话名；保留每个会话的起点/最新轮、分叉点/派出点轮次与子代理汇回点，其余普通轮次省略（同一会话相邻保留轮之间由泳道直线相连），因此能看出「从哪一轮分叉出去、子代理从哪一轮派出」（用户 2026-11-12 02:47 原话）。主线仍是当前正在查看的会话。
- 悬停分叉点/派出点节点时，tooltip 显示该轮标题；悬停名称行或连线时，左侧该会话的线与节点一起高亮。
- 命中区：连线透明描边两侧各 6px（列距 14px，相邻泳道不重叠），节点圆点命中区 20px，名称行整行可点（用户原话：拓扑图特别细，鼠标悬停很难选中 → 反馈0220#07）。
- 点节点/连线：分叉 → 打开该会话；子代理 → 打开只读子会话；当前会话 → 不跳转。行标题的标准 tooltip 保留（截断标题看全文）。
- **反馈模式（Ctrl+Shift+F）下浮层停住不消失**：`ui/HoverCard` 与菜单/Popover 同一套规则，指针离开触发器不收起（反馈0220#06，共享层修，不在 SessionRow 里特判）。

## 切分支（右栏会话图）

- 右栏会话图的主线永远是**当前打开的会话的祖先链**：打开分叉时，主线 = 来源会话分叉点之前的轮次 + 分叉自己的轮次，一条直线上去；来源会话在分叉点之后的轮次是完整分支泳道（不再画「原会话」单节点支线），主会话上的子代理同样可见。见 [session-graph.md](session-graph.md)。
- 子代理只读视图不切换主线：右栏仍是其父会话的会话图，点主线节点先退出子代理视图再定位（沿用反馈1926#03）。
- 用户原话说「最右边的主线要换成对应的会话」；现行画法主线固定在第 0 列（最左），按产品经理的要求保持轨道位置不变，只替换主线代表的会话。

## 右栏代理卡（子代理列表）

- 一行一个子代理（按层级缩进 + 竖引导线），点行打开该子代理的只读会话；行尾不再有常驻 ⋯ 按钮（2026-11-12 用户原话「去掉」）。
- 「换模型重跑 / 交回主会话（单代理）」改为右键子代理行打开同一组操作；运行中的行不弹菜单。
