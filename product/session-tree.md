# TREE 会话树

## 看清并在会话树里移动（会话图）
**用户要做的事**：理解一棵会话树的结构和进展，并在里面跳转。

**要达到的效果**
- **E1 结构真实**：图反映树本身，不随"从哪个会话看"而改变；从哪看只决定"我在哪条线上"。
- **E2 一眼分得清**：不同会话的线一眼能区分；自己当前在哪条线、哪一轮一眼可见。
- **E3 状态一眼可见**：哪条线在跑、哪条线在等我处理，不用点开就知道。
- **E4 看到的就能到达**：图上任何一轮、任何会话都能直接跳过去。
- **E5 只呈现理解结构所需的信息**：图上的每个元素都在帮助回答"树长什么样、我在哪、谁在动"。

**行为**
- **TREE-1**（E1）树里所有会话的所有轮都是节点；在树里任何会话打开，节点和连线都相同。
  例：R 有 r1–r6，r3 分出 F（f1–f3），r5 派出子代理 S。打开 R 或打开 F，都是这 12 个节点、同样的连线。
- **TREE-2**（E2）当前会话的祖先链是主线，一条直线。上例打开 F：主线是 r1–r3、f1–f3；R 的 r4–r6 从 r3 分出。在子代理视图里，主线是它的父会话。
- **TREE-3**（E2）当前所在轮有明显标记；悬停某个节点或某条线时，该会话整条线突出、被悬停的那一轮更突出。
- **TREE-4**（E3）正在输出的会话、等待审批或回答的会话，其最新一轮各有一种标记，两种标记能区分。主会话、分叉、子代理都适用。
- **TREE-5**（E4）点当前主线上的轮 → 跳到该轮（与轮次大纲同一种跳转）；点其他会话的轮或线 → 打开那个会话（子代理以只读方式打开）；在子代理视图里点主线 → 回主会话并定位。外部会话同样可点。
- **TREE-6**（E4）细线和小节点也容易点中、容易悬停。

**定过的取法**
- 整棵树共用一张图、只换主线，仿照 git 图（2026-11-12）——为 E1。
- 不同会话用不同颜色的泳道（2026-11-09）——为 E2，让线好区分。
- 轨道式画法：统一线宽、正交折线、颜色不调淡（2026-11-11）——为 E2。
- 最新一轮在最上（2026-11-11）。
- 节点只写该轮用户消息首行（2026-11-11）——为 E5。

## 一棵树在侧栏只占一行
**用户要做的事**：在会话列表里找到并打开一棵会话树，看出它的状态。

**要达到的效果**
- **E6 列表不被分叉和子代理刷屏**：一棵树一行。
- **E7 状态不用点开就知道**：树里任何会话在跑、在等、有未读，这一行都看得出来。
- **E8 不离开列表就能看结构**：需要时可以直接看到这棵树的形状并跳到其中某个会话。

**行为**
- **TREE-10**（E6）分叉不新增侧栏行；行标题是根会话标题；当前打开的是分叉时行内标出分叉名；子代理不进侧栏。
- **TREE-11**（E6）点这一行，打开树里最近活动的会话。
- **TREE-12**（E7）未读、运行中、待审批按树内任一会话汇总显示，优先级：待审批 > 运行中 > 错误 > 空闲。已读状态会保存，重启后不复现。
- **TREE-13**（E6）超过 7 天没活动的会话收起为「更早的 N 个会话」，点开才加载；固定、运行中、待审批、未读的始终显示；展开状态按项目记住。
- **TREE-14**（E8）悬停会话行，弹出这棵树的紧凑会话图（与 TREE-1 同一张图）：只在会话起点写会话名，保留每个会话的起点、最新一轮、所有分叉点与派出点、子代理汇回点。悬停名称行时对应的线突出；点节点、线或名称行跳到对应会话。树里只有一个会话时不弹。
- **TREE-15**（E8）反馈模式下，弹出的拓扑图停住，方便标注。

**定过的取法**
- 分叉与原会话共用一行（2026-11-11）——为 E6。
- 紧凑图必须画出分叉点与派出点（2026-11-12）——为 E8，否则看不出拓扑关系。

## 进入子代理
**用户要做的事**：看清子代理做了什么，必要时换个模型重跑或交回主会话。

**要达到的效果**
- **E9 一步进入、每次都成功**：从任何地方看到子代理，都能一步进入它的会话。

**行为**
- **TREE-20**（E9）点对话流里的子代理工具行、会话图里的子代理节点、右栏代理列表里的行，都直接打开该子代理的只读会话。
- **TREE-21**（E9）无论从主会话、分叉还是另一个子代理进入，子代理的消息都能加载出来。
- **TREE-22**（E9）只读视图顶部显示"只读 · 主会话 › 子代理"，可一步返回。
- **TREE-23** 在代理列表上右键子代理，可"换模型重跑""交回主会话"；运行中的不可操作。

## 分叉
**用户要做的事**：从某一轮另开一条路，并随时能回到来源。

**要达到的效果**
- **E10 分叉是可回溯的**：分叉知道自己从哪来，随时能回去。

**行为**
- **TREE-30**（E10）在任一轮的消息操作里选「分叉」，新会话从该轮之后开始，共享之前的历史。
- **TREE-31**（E10）分叉会话顶部「分叉自 …」的「查看」回到来源会话并定位分叉点。
