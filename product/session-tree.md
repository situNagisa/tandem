# TREE 会话树

## 会话图
目标：一眼看清这棵会话树——每一轮、从哪分叉、子代理从哪派出、谁在跑谁在等——并能跳到任意一轮或任意会话。
入口：右栏「会话图」卡片（可全高展开）。

- **TREE-1 一棵树一张图**：树里所有会话的所有轮都是节点。在树里任何会话打开，节点和连线都相同，只是主线不同。
  例：R 有 r1–r6，r3 分出 F（f1–f3），r5 派出子代理 S。打开 R：主线 r1–r6，F 从 r3 分出，S 挂在 r5。打开 F：主线 r1–r3、f1–f3 一条直线，R 的 r4–r6 从 r3 分出成分支，S 仍挂在 r5。两张图节点数相同。
- **TREE-2 主线是当前会话**：当前会话的祖先链画在主线轨道上，一条直线；在子代理视图里，主线仍是它的父会话。
- **TREE-3 最新在上**：时间倒序，最新一轮在最上面。
- **TREE-4 只显示必要的字**：每个节点只有该轮用户消息的首行；分叉起点标「分叉」。
- **TREE-5 在跑与在等**：任何正在输出的会话（主会话、分叉、子代理），其最新一轮节点有呼吸动画；等待审批或回答的，用待审批色标记，悬停写"等待你的输入/审批"。
- **TREE-6 悬停**：悬停某个节点或某条线：该会话整条线高亮、其他线变暗；被悬停的节点额外放大；只有指针所在那一行标题有悬停底色；tooltip 写会话名（分叉点/派出点写该轮标题）。线和节点的可点区域足够大，细线也容易点中。
- **TREE-7 点击**：点当前会话主线上的节点 → 跳到该轮（与轮次大纲同一种跳转，见 CONV 的跳转行为）；点其他会话的节点或线 → 打开那个会话（子代理打开只读视图）；在子代理视图里点主线节点 → 回到主会话并定位该轮。外部会话的图同样可点定位。
- **TREE-8 高度**：卡片内按行数自适应，最少 3 行、最多 12 行，超出后内部滚动。

不做：显示轮次序号、token、耗时；摘要行（"N 轮 · N 子代理"）；展开/收起按钮；跳转后高亮消息。
决定：
- 仿照 git 图，整棵树共用一张拓扑（2026-11-12，产品所有者："拓扑结构完全是一样的，只是主线不同"）。
- 轨道式画法、泳道保持彩色（2026-11-11 选打分卡 B，颜色不调淡）。
- 主线放在第 0 列（最左），只替换主线代表的会话（2026-11-11，产品经理）。

## 侧栏会话行
目标：一棵会话树在侧栏只占一行，并能看出它的状态与结构。
入口：侧栏会话列表。

- **TREE-10 一树一行**：分叉不新增侧栏行；行标题是根会话标题；当前打开的是分叉时，行内用小字标出分叉名。子代理不进侧栏。
- **TREE-11 点击打开最近活动的会话**：点这一行，打开树里最近活动的那个会话（主会话或某个分叉）。
- **TREE-12 状态汇总**：行上的未读/运行中/待审批按树内任一会话汇总，优先级：待审批 > 运行中 > 错误 > 空闲。
- **TREE-13 已读会保存**：打开过会话后未读消失，重启后不再出现。
- **TREE-14 更早的会话收起**：项目分组里超过 7 天没活动的会话默认收起为一行「更早的 N 个会话」，点开才加载；固定、运行中、待审批、未读的会话始终显示；展开状态按项目记住。
- **TREE-15 悬停拓扑图**：悬停会话行，右侧弹出这棵树的紧凑会话图（与 TREE-1 同一张图）：不显示轮次标题，只在每个会话起点写会话名；保留会话起点、最新轮、所有分叉点与派出点、子代理汇回点，其余轮省略。悬停名称行时对应的线高亮；点节点、线或名称行跳到对应会话。树里只有一个会话时不弹。反馈模式下悬停卡片停住不消失。

不做：分叉单独占一行；跨主机派单（已并入新会话页选主机）。
决定：
- 分叉与原会话共用一行（2026-11-11 22:09 原话）。
- 拓扑图必须包含分叉点与派出点（2026-11-12 02:47 原话："否则就只是一个点伸出好几条爪子"）。

## 子代理
目标：看清子代理做了什么，必要时换个模型重跑或交回主会话。
入口：对话流里的子代理工具行；会话图节点；右栏「代理」卡。

- **TREE-20 直接进入**：点对话流里的子代理工具行、会话图里子代理的节点、右栏代理卡里的子代理行，都直接打开该子代理的只读会话，不展开卡片。
- **TREE-21 每次都能加载**：无论从主会话、分叉还是另一个子代理进入，子代理会话的消息都能加载出来。
- **TREE-22 只读视图带面包屑**：顶部显示"只读 · 主会话 › 子代理"，可一步返回。
- **TREE-23 右键操作**：右栏代理卡上右键子代理行，可"换模型重跑""交回主会话"；运行中的不弹。

不做：代理卡行尾的 ⋯ 按钮（2026-11-12 原话"去掉"）。

## 分叉
目标：从某一轮另开一条路，并随时能回到来源。

- **TREE-30 从任一轮分叉**：消息操作里选「分叉」，新会话从该轮之后开始，共享该轮之前的历史。
- **TREE-31 回到来源**：分叉会话顶部「分叉自 …」的「查看」回到来源会话并定位分叉点。

不做：把编辑重发或回退画成分支（它们不持久化为分叉）。
