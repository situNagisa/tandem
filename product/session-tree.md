# TREE 会话树

> 状态：草稿，待确认。拥有：分叉、子代理、会话之间的关系。依赖 CONV（会话、轮）。核心模型：会话树归并（唯一实现见 `scripts/product-core-models.json`）。

一个会话可以分叉出新会话，也可以派出子代理；它们连同根会话组成一棵会话树。用户需要在任何时候看清这棵树长什么样、自己在哪、谁在动，并能一步到达树里任何地方。

## 会话图（右栏）

意图：像 git 图那样，一眼看懂一棵树的结构——从哪一轮分出去、子代理从哪派出、汇回到哪。安静、线条清楚，颜色只用来区分不同的会话线。参照：`approved/tree/graph-main.png`、`approved/tree/graph-fork.png`。

必须：
- **TREE-1** 一棵树只有一张图：树里所有会话的所有轮都是节点；在树里任何会话打开，节点和连线都相同。
  例：R 有 r1–r6，r3 分出 F（f1–f3），r5 派出子代理 S。打开 R 或打开 F，都是这 12 个节点、同样的连线。
- **TREE-2** 当前会话的祖先链是主线，画成一条直线：上例打开 F，主线是 r1–r3、f1–f3，R 的 r4–r6 从 r3 分出。在子代理视图里，主线是它的父会话。
- **TREE-3** 正在输出的会话、在等审批或回答的会话，各自最新一轮有可区分的标记；主会话、分叉、子代理都适用。
- **TREE-4** 点当前主线上的一轮 → 跳到该轮，与轮次大纲同一种跳转；点其他会话的轮或线 → 打开那个会话（子代理只读打开）；在子代理视图里点主线 → 回主会话并定位。外部会话的图同样可点。
- **TREE-5** 悬停一个节点或一条线：能看出这是哪个会话（整条线突出、提示会话名），也能看出指着的是哪一轮。

定过的取法（要改先问）：仿照 git 图、整棵树一张图（2026-11-12）；不同会话不同颜色、轨道式画法、颜色不调淡（2026-11-09、2026-11-11）；最新在上（2026-11-11）。

自由：节点大小、线宽、间距、高度上限、tooltip 文案、动画样式，只要符合意图。

## 侧栏：一棵树一行

意图：会话列表不被分叉和子代理刷屏，但一棵树的状态和形状不用点开就能知道。参照：`approved/tree/sidebar-topology.png`。

必须：
- **TREE-10** 分叉不新增侧栏行，和根会话共用一行；子代理不进侧栏。点这一行打开树里最近活动的会话；当前打开的是分叉时，行内能看出在哪个分叉。
- **TREE-11** 行上的未读、运行中、待审批按树内任一会话汇总；已读会保存，重启后不复现。
- **TREE-12** 很久没动的会话（超过 7 天）默认收起，点开才加载；固定、运行中、待审批、未读的始终显示。
- **TREE-13** 悬停会话行弹出这棵树的紧凑图：与 TREE-1 是同一张图的缩略，必须画出每个会话的起点、所有分叉点与派出点，能看出拓扑关系；点上面的会话能跳过去。树里只有一个会话时不弹。
- **TREE-14** 反馈模式下，这张紧凑图停住不消失。

定过的取法：分叉与原会话共用一行（2026-11-11）；紧凑图必须画出分叉点与派出点（2026-11-12）。

自由：行内分叉名的写法、收起行的文案、紧凑图里省略哪些普通轮。

## 子代理与分叉

必须：
- **TREE-20** 在任何地方看到子代理（对话流里的子代理行、会话图节点、代理列表），都能一步进入它的只读会话；无论从主会话、分叉还是另一个子代理进入，消息都能加载出来；只读视图能一步回到父会话。
- **TREE-21** 代理列表里可以对子代理"换模型重跑""交回主会话"。
- **TREE-22** 在任一轮可以分叉；分叉会话能一步回到来源会话的分叉点。

自由：这些操作放在哪个菜单、用什么图标。
